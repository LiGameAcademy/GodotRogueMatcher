# 音效设计文档 (Audio Design Document)

---

## 一、设计原则 (Design Principles)

### 1. 核心原则
- **反馈性：** 每个操作都有音效反馈
- **沉浸感：** 音效增强游戏氛围
- **不干扰：** 音效不干扰游戏体验
- **可调节：** 支持音量调节

### 2. 优先级
- **高优先级：** UI 音效、消除音效（核心反馈）
- **中优先级：** 背景音乐、环境音效
- **低优先级：** 细节音效（未来扩展）

---

## 二、音效分类 (Audio Categories)

### 1. UI 音效 (UI Sound Effects)

#### 1.1 点击音效
- **触发：** 按钮点击、菜单选择
- **风格：** 清脆的机械键盘声
- **时长：** 0.1-0.2 秒
- **音调：** 中高音调
- **文件：** `ui_click.ogg`

#### 1.2 购买音效
- **触发：** 购买物品成功
- **风格：** 收银机声或电子确认音
- **时长：** 0.3-0.5 秒
- **音调：** 中音调，上升音调
- **文件：** `ui_purchase.ogg`

#### 1.3 错误音效
- **触发：** 操作失败（金币不足、位置无效）
- **风格：** 低沉的错误音
- **时长：** 0.2-0.3 秒
- **音调：** 低音调，下降音调
- **文件：** `ui_error.ogg`

#### 1.4 悬停音效（可选）
- **触发：** 鼠标悬停在按钮上
- **风格：** 轻微的电子音
- **时长：** 0.1 秒
- **音调：** 高音调
- **文件：** `ui_hover.ogg`

---

### 2. 游戏音效 (Gameplay Sound Effects)

#### 2.1 消除音效
- **触发：** 发生消除
- **风格：** 合成器电子音，类似"叮"或"嗡"
- **时长：** 0.3-0.5 秒
- **音调：** 中高音调
- **变化：** 根据消除数量调整音调
  - 5连：基础音调
  - 6连：+1 半音
  - 7连：+2 半音
  - 8连及以上：+3 半音
- **文件：** `sfx_match.ogg`

#### 2.2 连击音效
- **触发：** 触发连锁消除
- **风格：** 音调递增的电子音（Do, Re, Mi...）
- **时长：** 0.2-0.3 秒/次
- **音调：** 每次连锁音调递增
- **文件：** `sfx_combo.ogg`

#### 2.3 冲击波音效
- **触发：** 消除产生冲击波
- **风格：** 低沉的"嗡"声，类似能量波
- **时长：** 0.4-0.6 秒
- **音调：** 低中音调
- **文件：** `sfx_shockwave.ogg`

#### 2.4 球体移动音效
- **触发：** 球体移动（可选，可能过于频繁）
- **风格：** 轻微的滑动音
- **时长：** 0.1-0.2 秒
- **音调：** 低音调
- **文件：** `sfx_move.ogg`（可选）

#### 2.5 炸弹爆炸音效
- **触发：** 炸弹爆炸
- **风格：** 爆炸音，带有电子感
- **时长：** 0.5-0.8 秒
- **音调：** 中低音调
- **文件：** `sfx_bomb.ogg`

#### 2.6 建筑放置音效
- **触发：** 放置建筑
- **风格：** 机械放置音，类似"咔"
- **时长：** 0.2-0.3 秒
- **音调：** 中音调
- **文件：** `sfx_building_place.ogg`

#### 2.7 建筑回收音效
- **触发：** 回收建筑
- **风格：** 反向的放置音
- **时长：** 0.2-0.3 秒
- **音调：** 中音调
- **文件：** `sfx_building_recycle.ogg`

### 3. 威胁音效 (Threat Sound Effects)

#### 3.1 死像素生成音效
- **触发：** 生成死像素
- **风格：** 低沉的"故障"音，类似"哔"
- **时长：** 0.3-0.4 秒
- **音调：** 低音调
- **文件：** `sfx_dead_pixel.ogg`

#### 3.2 粘滞扇区生成音效
- **触发：** 生成粘滞扇区
- **风格：** 轻微的"粘滞"音
- **时长：** 0.2-0.3 秒
- **音调：** 中低音调
- **文件：** `sfx_sticky_sector.ogg`

#### 3.3 安全等级提升音效
- **触发：** 安全等级提升
- **风格：** 警报音，类似"嘟"
- **时长：** 0.5-0.8 秒
- **音调：** 中音调，上升音调
- **文件：** `sfx_security_level.ogg`

#### 3.4 危险警告音效
- **触发：** 剩余空位 < 10
- **风格：** 持续低沉的蜂鸣声
- **时长：** 持续（循环播放）
- **音调：** 低音调
- **文件：** `sfx_warning.ogg`

#### 4.1 关卡完成音效

## 三、背景音乐 (Background Music)

### 1. 设计原则
- **优先级：** 中等（不是核心功能）
- **风格：** 电子/合成器音乐，符合赛博风格
- **音量：** 较低，不干扰游戏音效
- **循环：** 无缝循环

### 2. 音乐类型

#### 2.1 主菜单音乐
- **风格：** 轻松、科技感
- **时长：** 2-3 分钟（循环）
- **文件：** `bgm_menu.ogg`

#### 2.2 游戏音乐
- **风格：** 紧张、节奏感强
- **变化：** 根据安全等级调整强度
  - Lv.1-2：轻松版本
  - Lv.3：中等强度
  - Lv.4+：高强度版本
- **时长：** 3-5 分钟（循环）
- **文件：** `bgm_game.ogg`, `bgm_game_intense.ogg`

#### 2.3 胜利音乐
- **风格：** 胜利、庆祝
- **时长：** 10-15 秒
- **文件：** `bgm_victory.ogg`

## 四、音量系统 (Volume System)

### 1. 音量分类
- **主音量 (Master Volume)：** 控制所有音效
- **音效音量 (SFX Volume)：** 控制游戏音效
- **音乐音量 (Music Volume)：** 控制背景音乐
- **UI 音量 (UI Volume)：** 控制 UI 音效（可选，可合并到 SFX）

### 2. 默认音量
- **主音量：** 80%
- **音效音量：** 90%
- **音乐音量：** 70%

### 3. 音量调节
- **位置：** 设置菜单
- **方式：** 滑块调节（0-100%）
- **保存：** 保存到设置文件

## 五、音效实现 (Audio Implementation)

### 1. Godot 音频系统

#### 1.1 AudioStreamPlayer
- **用途：** 播放一次性音效（UI、游戏音效）
- **特点：** 可以同时播放多个实例

#### 1.2 AudioStreamPlayer2D
- **用途：** 播放空间音效（未来扩展）
- **特点：** 支持 2D 空间定位

#### 1.3 AudioStreamPlayer（背景音乐）
- **用途：** 播放背景音乐
- **特点：** 单个实例，无缝循环

### 2. 音效管理器

```gdscript
# AudioManager.gd (Autoload)
extends Node

@export var master_volume: float = 0.8
@export var sfx_volume: float = 0.9
@export var music_volume: float = 0.7

var sfx_players: Array[AudioStreamPlayer] = []
var music_player: AudioStreamPlayer

func _ready():
    # 创建音效播放器池
    for i in range(10):
        var player = AudioStreamPlayer.new()
        add_child(player)
        sfx_players.append(player)
    
    # 创建音乐播放器
    music_player = AudioStreamPlayer.new()
    add_child(music_player)

func play_sfx(sound_name: String):
    var player = get_available_sfx_player()
    if player:
        var stream = load("res://assets/audio/sfx/" + sound_name + ".ogg")
        player.stream = stream
        player.volume_db = linear_to_db(sfx_volume * master_volume)
        player.play()

func play_music(music_name: String):
    var stream = load("res://assets/audio/bgm/" + music_name + ".ogg")
    music_player.stream = stream
    music_player.volume_db = linear_to_db(music_volume * master_volume)
    music_player.play()

func get_available_sfx_player() -> AudioStreamPlayer:
    for player in sfx_players:
        if not player.playing:
            return player
    # 如果所有播放器都在使用，创建新的
    var player = AudioStreamPlayer.new()
    add_child(player)
    sfx_players.append(player)
    return player
```

## 六、音效资源规范 (Audio Asset Specifications)

### 1. 文件格式
- **格式：** OGG Vorbis（Godot 推荐）
- **采样率：** 44.1kHz
- **位深：** 16 位
- **声道：** 单声道（音效），立体声（音乐）

### 2. 文件命名
- **音效：** `sfx_<name>.ogg`
- **UI 音效：** `ui_<name>.ogg`
- **背景音乐：** `bgm_<name>.ogg`

### 3. 文件大小
- **音效：** 尽量小（< 100KB）
- **音乐：** 可以较大（< 2MB）

## 七、音效触发时机 (Audio Trigger Points)

### 1. UI 音效触发
- 按钮点击
- 菜单打开/关闭
- 购买成功/失败
- 设置更改

### 2. 游戏音效触发
- 消除发生
- 连锁触发
- 冲击波产生
- 建筑放置/回收
- 威胁生成

### 3. 事件音效触发
- 关卡完成
- 游戏失败
- 宝箱解锁
- 黑市激活

## 八、未来扩展 (Future Extensions)

### 1. 动态音乐
- **根据游戏状态调整：** 根据安全等级、剩余空间等调整音乐强度
- **无缝过渡：** 不同状态间无缝过渡

### 2. 空间音效
- **2D 定位：** 使用 AudioStreamPlayer2D 实现空间音效
- **距离衰减：** 根据距离调整音量

### 3. 音效变体
- **随机变体：** 同一音效的多个变体，随机播放
- **音调变化：** 根据游戏状态调整音调

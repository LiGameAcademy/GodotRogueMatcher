## 规则与所有权

- 新增稀有单级卡“主动扫线”：任一行/列补给已解锁时可抽取；取得后两类扫线手均可双击释放。试调权重10沿用“主动爆破”，不代表平衡已验证。
- 卡牌采用 SkillLevelDefinition → AbilityDefinition → InstallLineUpgradeEffect，通过现有选择流水线安装本局独占升级。配置 Resource 只读，计数归 SkillInstance/LineClearState。
- ActivateLineCommand 消耗来源棋子、推进1次有效行动并正常补棋。只触发来源固有离场能力一次；主动路径不另做第二次扫线。
- 扫除普通棋子与引信，保留其他特殊伙伴。引信进入既有移除队列并连锁；重叠目标只按实际存活集合移除、计分。
- 直接扫线的基础分为 n×(n+5)：1/2/4/5枚分别为6/14/36/50分，再应用全局倍率与额外得分。空轴0分；扫线不冒充同色五连专属触发。来源消耗本身不算直接命中。
- 行动开始冻结已预告补棋代价；本次行动引起升压不会改变本批数量。完整根行动及正常补棋收束后检验阶段目标。阶段行动得分统计补入 line_clear 来源。
- 空轴二次确认按此前授权暂缓：目前空轴双击仍消耗来源、一次行动并正常补棋。

## 动效检查与处理

当前 BoardView 的范围动效入口仅识别 explosion；#92 的 line_clear 结果有棋子离场与漂字，没有范围演出接入。检查现有 Git 历史未找到行列专用范围动效被删除的证据，不将作者反馈归因为已证实的覆盖提交。

新增同名场景/脚本 LineClearVisual，消费冻结的轴向和坐标，在整行或整列播放低亮度扫光。表现参数由 BoardJuiceConfig 管理，默认0.38秒；支持快放、暂停、低特效、F9跳过和重试取消。扫线使用已有 blast 音效请求。动画不查询活棋盘，不参与清除或计分。

## 作者试玩

1. 重启游戏进程加载本分支，按 F11（编辑器调试构建）进入 fixture_line。
2. 双击左上角行清除手：清除同行两枚普通棋，得到14基础分，整行扫光，正常补3枚。
3. 双击列清除手：验证扫光方向和同列目标，其他轴棋子保留。可先移动它，检查离场按新坐标扫线。
4. 切换 F8 快放、F9 跳过、低特效及暂停，确认结束后输入恢复、棋盘与分数一致。
5. 正常局取得行/列登场后，检查“主动扫线”的卡面、选择、持有状态与棋子 tooltip。

F11记录标记为 fixture，只用于规则与体验检查，不纳入玩家或机器人平衡样本。

# 林道开辟调整（#93）

作者试玩认为反馈弱，希望减少出现频率，同时去掉「清理不得分」限制。

- 基础抽选权重 8→3 为试调值；高压救场权重仍由原压力规则计算，3 是基础权重而非最终概率。
- 对候选预告中冻结的一行/列普通材料直接消除、得分；保留特殊伙伴，引信照常触发爆炸。
- 每批清理的基础分为 n*(n+5)，含不足五枚；使用已有全局分数倍率与消除额外得分，带标记收益计一次，后续爆炸分独立入账。例：无强化五枚50分、两枚14分、一枚6分。
- 这种混色清理属于技能消除，不冒充同色五连，不触发精准五连、长线、五连种引信或五连染色。
- `ClearMaterialEffect.score_cleared` 为只读配置；仅林道开辟打开，清色和其他清理卡仍沿用各自原规则。普通五连最低数量及行列清除手的短轴计分均不在本片修改。
- 直接清理返回带分数的 MatchResult，消除与漂字只播放一次；预算/目标失效先拒绝，重复 command 不重复扣奖励或得分，组合延迟离场队列保持原顺序。
- 规则版本为 run-commands-v27-forest-clear-score，记录分开保存直接技能消除和爆炸得分。

卡面改为「消除一条行或列的普通棋。得分并触发效果。」。作者试玩时检查预告列/行、总分变化、引信连锁与清理动画；基础权重需要后续结合整池试玩调节。

# 爆破手预告颜色修复（#51）

作者试玩发现自然补棋的爆破手始终绿色，即使预告显示其他颜色。原实现锁定了普通颜色，却在出生时改用固定core_color，生成入口又使用配置默认绿色，导致预告与实际匹配颜色不一致。

修复后，自然补棋使用同一个锁定颜色，不再次抽取颜色。记录令牌的color与core_color同步，爆破手生成入口显式接收该颜色；如果场上已有爆破手，同一令牌回退为同色普通棋。伙伴能力安装和唯一性保留。

作者再次反馈后，核对最近的v12试玩记录：首枚来自选卡，仍使用旧设定的固定绿色；随后自然补棋的一枚预告和实际均为绿色，没有在该局记录中发现非绿色预告被改色。作者确认首枚也按棋子池权重抽色。本次补齐这条路径：候选生成时通过独立目标随机流锁定颜色，卡面显示“立即投放：颜色”，预算预检及实际投放均使用它。重复查看、选卡和后续权重变化不重抽，不消费普通补棋预告。非法颜色拒绝并保留奖励。教学与调试固定盘面继续使用默认颜色。

运行规则版本更新为run-commands-v13-core-offer-color，旧版记录不按新规则声称精确重放；原始文件保留，字段格式不变。

Godot4.7.2/GUT9.6.0、固定60fps：本轮相关78项分批通过，覆盖首枚与自然补棋的五色真实可见图形、出生动画和重建、真实卡面锁色、无效颜色、非绿色预算拒绝、首枚正常命令逐检查点回放，以及生成预告、技能、爆破、阶段和采集。首枚锁色回归在本次修复前失败，真实自然补棋显示通过。历史卡面用例硬编码旧规则配置哈希导致失败，改为直接验证展示字段不入规则配置且渲染不改状态；不再把固定旧玩法哈希当作UI契约。相关文件≤500行。日志：.godot/core-skill-before.log、core-skill-after.log、core-skill-final.log。

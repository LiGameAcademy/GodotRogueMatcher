# 爆破手预告颜色修复（#51）

作者试玩发现自然补棋的爆破手始终绿色，即使预告显示其他颜色。原实现锁定了普通颜色，却在出生时改用固定core_color，生成入口又使用配置默认绿色，导致预告与实际匹配颜色不一致。

修复后，自然补棋使用同一个锁定颜色，不再次抽取颜色。记录令牌的color与core_color同步，爆破手生成入口显式接收该颜色；如果场上已有爆破手，同一令牌回退为同色普通棋。伙伴能力安装和唯一性保留。技能直接召唤与教学样例不传颜色时仍使用原配置默认值。

运行规则版本更新为run-commands-v12-core-preview-color，旧版记录不按新规则声称精确重放；原始文件保留，字段格式不变。

Godot4.7.2/GUT9.6.0：相关61项测试分批通过，含五色预告与实际一致、已有伙伴的普通棋回退、五种颜色参与五连、正常命令生成非绿色伙伴的逐检查点回放、爆破、HUD与BoardView。修复前新增两项回归均失败；修复后通过。HUD计分动画用例首次未固定帧率失败，按项目60fps配置复验15项全通过，未调整动画代码。相关文件≤500行。

# 物品系统设计 (Item System Design)

---

## 一、设计原则 (Design Principles)

**核心原则：** 万物皆实体，一切皆占地。

每个物品都占用棋盘空间，玩家需要在"获得收益"和"占用空间"之间做出权衡。

---

## 二、物品分类 (Item Categories)

### 1. 建筑类 (Constructs) - 核心得分手段

建筑类物品占用空间，提供持续效果，是构筑系统的核心。

#### 1.1 棱镜塔 (Prism Tower)
- **稀有度：** 普通
- **占用空间：** 1 格
- **效果：** 
  - 视为万能色，可以参与任何颜色的消除
  - 参与消除时，该次消除得分 x2
- **策略价值：** 高（核心得分建筑）
- **放置限制：** 无特殊限制

#### 1.2 染色工厂 (Dye Station)
- **稀有度：** 普通
- **占用空间：** 1 格
- **效果：** 
  - 每回合开始时，将上下左右 4 格中的 1 个随机球染成指定颜色
  - 玩家可以选择目标颜色（放置时选择）
- **策略价值：** 中等（策略性建筑）
- **放置限制：** 无特殊限制

#### 1.3 增幅器 (Amplifier)
- **稀有度：** 普通
- **占用空间：** 1 格
- **效果：** 
  - 自身不参与消除
  - 周围 8 格发生的消除，基础分 +100%
  - 效果可叠加（多个增幅器）
- **策略价值：** 中等（区域增益）
- **放置限制：** 无特殊限制

#### 1.4 空间压缩机 (Space Compressor)
- **稀有度：** 稀有
- **占用空间：** 1 格
- **效果：** 
  - 新生成的球有 20% 几率是"幽灵球"
  - 幽灵球不占碰撞体积，可以重叠
  - 幽灵球可以正常消除
- **策略价值：** 高（缓解空间压力）
- **放置限制：** 无特殊限制

---

### 2. 遗物类 (Relics) - 被动光环

遗物类物品占用空间，提供全局被动效果。

#### 2.1 以太图腾 (Ether Totem)
- **稀有度：** 稀有
- **占用空间：** 1 格
- **效果：** 
  - 所有红球消除得分 x1.5 倍率
  - 效果全局生效
- **策略价值：** 高（如果主要使用红球）
- **放置限制：** 无特殊限制

#### 2.2 能量核心 (Energy Core)
- **稀有度：** 稀有
- **占用空间：** 1 格
- **效果：** 
  - 所有消除得分 +50%
  - 效果全局生效
- **策略价值：** 高（全局增益）
- **放置限制：** 无特殊限制

## 三、物品数据结构 (Item Data Structure)

### 1. ItemData Resource

```gdscript
class_name ItemData extends Resource

@export var id: String  # 唯一标识符
@export var name: String  # 显示名称
@export var name_en: String  # 英文名称（本地化）
@export var description: String  # 描述
@export var description_en: String  # 英文描述
@export var icon: Texture2D  # 图标
@export var rarity: String  # "COMMON", "RARE", "EPIC"
@export var type: String  # "BUILDING", "RELIC"
@export var occupies_space: bool  # 是否占用空间
@export var effect_config: ItemEffectConfig  # 效果配置
```

### 2. 效果脚本系统

每个物品可以挂载自定义效果脚本：

## 四、物品生成系统 (Item Spawning)

### 1. 升级系统物品生成（三选一）

#### 1.1 生成规则
- **触发条件：** 达到分数里程碑
- **生成数量：** 3 个道具选项
- **生成方式：** 从物品池中随机选择
- **稀有度分布：** 根据等级调整稀有度概率

#### 1.2 物品池系统
```gdscript
var item_pools: Dictionary = {
    "common": [/* 常见物品 */],
    "rare": [/* 稀有物品 */],
    "epic": [/* 史诗物品 */]
}

func generate_level_up_options(level: int) -> Array[ItemData]:
    var options = []
    # 根据等级调整稀有度概率
    var rare_chance = min(0.1 + level * 0.05, 0.5)  # 最高 50%
    var epic_chance = min(0.05 + level * 0.02, 0.2)  # 最高 20%
    
    for i in range(3):
        var rand = randf()
        var pool = "common"
        if rand < epic_chance:
            pool = "epic"
        elif rand < rare_chance:
            pool = "rare"
        
        var item = get_random_item_from_pool(pool)
        options.append(item)
    
    return options
```

## 五、物品自动放置系统 (Auto Placement System)

### 1. 自动放置规则

#### 1.1 放置位置选择
- **随机空位：** 从棋盘所有空位中随机选择
- **避免边缘：** 优先选择中心区域（7x7 内，可选）
- **避免重叠：** 确保位置可用且无其他道具

#### 1.2 放置验证
```gdscript
func can_place_item_auto(board: Board, item: ItemData) -> bool:
    # 检查是否有空位
    var empty_cells = board.get_empty_cells()
    if empty_cells.is_empty():
        return false
    
    # 检查道具是否需要特殊位置（如钻头需要坏道）
    if item.placement_rules.has("BAD_SECTOR_ONLY"):
        var bad_sectors = board.get_bad_sectors()
        return not bad_sectors.is_empty()
    
    return true
```

### 2. 放置动画

#### 2.1 动画效果
- **从上方落下：** 道具从屏幕上方落下到目标位置
- **闪烁出现：** 道具在目标位置闪烁出现
- **缩放弹出：** 道具从 0 缩放到正常大小

#### 2.2 实现示例
```gdscript
func place_item_with_animation(board: Board, cell: Cell, item: ItemData) -> void:
    var item_node = item.scene.instantiate()
    cell.add_child(item_node)
    
    # 动画：从上方落下
    item_node.position.y = -100
    var tween = create_tween()
    tween.set_trans(Tween.TRANS_BACK)
    tween.set_ease(Tween.EASE_OUT)
    tween.tween_property(item_node, "position:y", 0, 0.3)
```

## 六、物品效果系统 (Item Effect System)

### 1. 效果触发时机

#### 1.1 回合开始效果
- **触发时机：** 每回合开始时
- **效果类型：** 染色工厂染色等

#### 1.2 消除时效果
- **触发时机：** 发生消除时
- **效果类型：** 棱镜塔倍率、增幅器增益等

#### 1.3 持续效果
- **触发时机：** 持续生效
- **效果类型：** 遗物光环效果

### 2. 效果叠加规则

#### 2.1 倍率叠加
- **乘法叠加：** 多个倍率效果相乘
- **例如：** 棱镜塔 x2 × 增幅器 +100% = x4

#### 2.2 增益叠加
- **加法叠加：** 多个增益效果相加
- **例如：** 多个增幅器 +100% +100% = +200%

## 七、物品平衡性 (Item Balance)

### 1. 效果平衡
- **效果强度：** 避免过强或过弱
- **使用场景：** 不同物品适合不同场景
- **组合效果：** 考虑物品组合的平衡性

## 八、未来扩展 (Future Extensions)

### 1. 新物品类型
- **陷阱类：** 对周围产生负面效果
- **传送门：** 连接两个位置
- **升级系统：** 建筑可以升级

### 2. 物品稀有度
- **普通：** 白色
- **稀有：** 蓝色
- **史诗：** 紫色
- **传说：** 橙色

### 3. 物品套装
- **套装效果：** 收集特定物品组合获得额外效果

# 物品系统设计 (Item System Design)

---

## 一、设计原则 (Design Principles)

**核心原则：** 万物皆实体，一切皆占地。

每个物品都占用棋盘空间，玩家需要在"获得收益"和"占用空间"之间做出权衡。

---

## 二、物品分类 (Item Categories)

### 1. 建筑类 (Constructs) - 核心得分手段

建筑类物品占用空间，提供持续效果，是构筑系统的核心。

#### 1.1 棱镜塔 (Prism Tower)
- **价格：** $15
- **占用空间：** 1 格
- **效果：** 
  - 视为万能色，可以参与任何颜色的消除
  - 参与消除时，该次消除得分 x2
- **策略价值：** 高（核心得分建筑）
- **放置限制：** 无特殊限制

#### 1.2 染色工厂 (Dye Station)
- **价格：** $10
- **占用空间：** 1 格
- **效果：** 
  - 每回合开始时，将上下左右 4 格中的 1 个随机球染成指定颜色
  - 玩家可以选择目标颜色（放置时选择）
- **策略价值：** 中等（策略性建筑）
- **放置限制：** 无特殊限制

#### 1.3 增幅器 (Amplifier)
- **价格：** $12
- **占用空间：** 1 格
- **效果：** 
  - 自身不参与消除
  - 周围 8 格发生的消除，基础分 +100%
  - 效果可叠加（多个增幅器）
- **策略价值：** 中等（区域增益）
- **放置限制：** 无特殊限制

#### 1.4 金矿 (Miner)
- **价格：** $8
- **占用空间：** 1 格
- **效果：** 
  - 每回合产出 $1 金币
  - 阻挡球的移动路径
  - 不可被消除
- **策略价值：** 低（长期收益，但占用空间）
- **放置限制：** 无特殊限制

---

### 2. 遗物类 (Relics) - 被动光环

遗物类物品占用空间，提供全局被动效果。

#### 2.1 以太图腾 (Ether Totem)
- **价格：** $20
- **占用空间：** 1 格
- **效果：** 
  - 所有红球消除得分 x1.5 倍率
  - 效果全局生效
- **策略价值：** 高（如果主要使用红球）
- **放置限制：** 无特殊限制

#### 2.2 空间压缩机 (Space Compressor)
- **价格：** $25
- **占用空间：** 1 格
- **效果：** 
  - 新生成的球有 20% 几率是"幽灵球"
  - 幽灵球不占碰撞体积，可以重叠
  - 幽灵球可以正常消除
- **策略价值：** 高（缓解空间压力）
- **放置限制：** 无特殊限制

---

### 3. 消耗品 (Consumables) - 救急与控场

消耗品使用后消失，提供一次性效果。

#### 3.1 炸弹 (Bomb)
- **价格：** $5
- **占用空间：** 1 格（放置时）
- **效果：** 
  - 放置后需点击引爆（或被其他爆炸波及引爆）
  - 炸毁 3x3 区域内的所有球
  - 不伤害建筑和死像素
- **策略价值：** 高（救急用，性价比高）
- **放置限制：** 只能放在空位上

#### 3.2 钻头 (Drill)
- **价格：** $10
- **占用空间：** 0 格（使用后消失）
- **效果：** 
  - 只能放在边缘"坏道"上
  - 将坏道转化为永久可用空地
  - 使用后消失
- **策略价值：** 高（解锁空间，战略价值）
- **放置限制：** 只能放在坏道上

#### 3.3 移位器 (Swapper)
- **价格：** $8
- **占用空间：** 0 格（使用后消失）
- **效果：** 
  - 允许交换两个建筑的位置
  - 使用后消失
- **策略价值：** 中等（优化布局，中后期有用）
- **放置限制：** 需要选择两个建筑位置

---

### 4. 交互实体 (Interactables) - 随机性来源

交互实体由系统生成，玩家通过消除激活。

#### 4.1 加密数据包 (Loot Box)
- **生成方式：** 随机刷新（低概率）
- **占用空间：** 1 格
- **效果：** 
  - **阻挡**球的移动
  - 周围发生消除时解锁（冲击波命中）
  - 解锁后提供"三选一"免费奖励：
    - 就地建造（免费放置一个建筑）
    - 获得金币（随机 5-15 金币）
    - 获得遗物（随机遗物效果）
- **策略价值：** 高（免费奖励）

#### 4.2 黑市终端 (Black Market)
- **生成方式：** 达成高连击刷新（如 7 连以上）
- **占用空间：** 1 格
- **效果：** 
  - **阻挡**球的移动
  - 有倒计时（如 3 回合）
  - 周围发生消除时激活（冲击波命中）
  - 激活后展开迷你商店（提供急救物资）
  - 倒计时结束后消失
- **策略价值：** 高（急救物资）

## 三、物品数据结构 (Item Data Structure)

### 1. ItemData Resource

```gdscript
class_name ItemData extends Resource

@export var id: String  # 唯一标识符
@export var name: String  # 显示名称
@export var name_en: String  # 英文名称（本地化）
@export var description: String  # 描述
@export var description_en: String  # 英文描述
@export var icon: Texture2D  # 图标
@export var price: int  # 价格
@export var type: String  # "BUILDING", "RELIC", "CONSUMABLE", "INTERACTABLE"
@export var occupies_space: bool  # 是否占用空间
@export var effect_script: Script  # 效果脚本
@export var placement_rules: Array[String]  # 放置规则（如 ["BAD_SECTOR_ONLY"]）
```

### 2. 效果脚本系统

每个物品可以挂载自定义效果脚本：

```gdscript
# PrismTowerEffect.gd
extends Node
class_name PrismTowerEffect

func on_match_made(match_data: Dictionary) -> Dictionary:
    # 修改消除数据
    match_data.score *= 2
    return match_data

func on_turn_start():
    # 回合开始时的效果
    pass
```

## 四、物品生成系统 (Item Spawning)

### 1. 商店物品生成

#### 1.1 生成规则
- **货架数量：** 3 个随机商品位 + 1 个固定位
- **固定位：** 钻头（始终可用）
- **随机位：** 从物品池中随机选择
- **刷新机制：** 支付金币刷新（$5 起步，每次递增）

#### 1.2 物品池系统
```gdscript
var item_pools: Dictionary = {
    "common": [/* 常见物品 */],
    "rare": [/* 稀有物品 */],
    "epic": [/* 史诗物品 */]
}

func generate_shop_items() -> Array[ItemData]:
    var items = []
    # 生成 3 个随机物品
    for i in range(3):
        var item = get_random_item_from_pool("common")
        items.append(item)
    # 添加固定物品（钻头）
    items.append(get_item_by_id("drill"))
    return items
```

### 2. 交互实体生成

#### 2.1 加密数据包生成
- **生成概率：** 每回合 2% 概率
- **生成位置：** 随机空位
- **生成限制：** 同时最多存在 2 个

#### 2.2 黑市终端生成
- **生成条件：** 达成 7 连或以上消除
- **生成概率：** 50% 概率
- **生成位置：** 随机空位
- **生成限制：** 同时最多存在 1 个

## 五、物品交互系统 (Item Interaction)

### 1. 放置系统

#### 1.1 放置验证
```gdscript
func can_place_item(item: ItemData, position: Vector2i) -> bool:
    # 检查金币
    if coins < item.price:
        return false
    
    # 检查位置是否可用
    if not is_available_cell(position):
        return false
    
    # 检查放置规则
    if not check_placement_rules(item, position):
        return false
    
    return true
```

#### 1.2 放置规则检查
```gdscript
func check_placement_rules(item: ItemData, position: Vector2i) -> bool:
    for rule in item.placement_rules:
        match rule:
            "BAD_SECTOR_ONLY":
                if not is_bad_sector(position):
                    return false
            "EMPTY_ONLY":
                if has_entity(position):
                    return false
    return true
```

### 2. 回收系统

#### 2.1 回收规则
- **可回收物品：** 建筑、遗物
- **不可回收物品：** 消耗品（使用后消失）、交互实体（系统生成）
- **回收价格：** 原价的 50%

#### 2.2 回收操作
```gdscript
func recycle_item(position: Vector2i) -> bool:
    var item = get_item_at(position)
    if item == null or not item.can_recycle:
        return false
    
    # 移除物品
    remove_item(position)
    
    # 返还金币
    coins += item.price * 0.5
    
    return true
```

## 六、物品效果系统 (Item Effect System)

### 1. 效果触发时机

#### 1.1 回合开始效果
- **触发时机：** 每回合开始时
- **效果类型：** 金矿产出、染色工厂染色等

#### 1.2 消除时效果
- **触发时机：** 发生消除时
- **效果类型：** 棱镜塔倍率、增幅器增益等

#### 1.3 持续效果
- **触发时机：** 持续生效
- **效果类型：** 遗物光环效果

### 2. 效果叠加规则

#### 2.1 倍率叠加
- **乘法叠加：** 多个倍率效果相乘
- **例如：** 棱镜塔 x2 × 增幅器 +100% = x4

#### 2.2 增益叠加
- **加法叠加：** 多个增益效果相加
- **例如：** 多个增幅器 +100% +100% = +200%

## 七、物品平衡性 (Item Balance)

### 1. 价格平衡
- **基础价格：** 根据效果强度设定
- **性价比：** 考虑空间占用成本
- **调整原则：** 通过测试数据调整

### 2. 效果平衡
- **效果强度：** 避免过强或过弱
- **使用场景：** 不同物品适合不同场景
- **组合效果：** 考虑物品组合的平衡性

---

## 八、未来扩展 (Future Extensions)

### 1. 新物品类型
- **陷阱类：** 对周围产生负面效果
- **传送门：** 连接两个位置
- **升级系统：** 建筑可以升级

### 2. 物品稀有度
- **普通：** 白色
- **稀有：** 蓝色
- **史诗：** 紫色
- **传说：** 橙色

### 3. 物品套装
- **套装效果：** 收集特定物品组合获得额外效果

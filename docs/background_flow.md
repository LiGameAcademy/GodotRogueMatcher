# 流动背景与得分响应（#30）

设置 / F1 →「动态背景」。默认开启，独立保存偏好；旧文件没有此字段时默认开启，非法值保持默认。两套主题使用各自底色与配色，低特效优先显示纯色，关闭后保留动态背景开关的偏好。

原创正弦扭曲宽色带在画面边缘缓慢流动，中央衰减。棋盘、面板、卡牌仍用不透明底板，文字不参与 Shader。明亮主题对比强度0.12，深色0.18；这是首轮试调参数，观感待作者试玩。格子保留已验收的纯色哑光，不重新增加格子渐变。

## 生命周期与边界

- `GameBackground` 是独立场景，根节点同名脚本，显式接收 GameTheme 与已提交得分。为保留现有场景引用，在 Game 中仍实例化为 `ColorRect`。
- GameTheme 组合只读 `BackgroundFlowConfig`；速度0.25弧度/秒，得分响应上限0.025，按150分达到最大响应，1.6秒线性消退。连携累加也不超过上限。
- 使用独立表现时钟、显式 PAUSABLE，不用 Shader TIME：ESC、设置及选卡暂停时冻结；快放不加速背景。重试/调试盘面清零相位和响应；切换主题保留相位、清除旧响应。
- 低特效或关闭开关时移除 ShaderMaterial、停止处理，显示纯色；恢复后从冻结相位继续，不补算停用时的得分。
- ShaderMaterial 在 ready 时复制。实例A、B和场景模板互不影响；主题 Resource 不写运行值。
- 沿用得分表现的回执，追加轻微色带响应，不追加规则、随机调用、计分或演出等待，不修改记录协议。#31棋盘后处理不在本片。

## 桌面帧间隔基线

Windows、i7-9700KF、RTX2070，Godot4.7.2 Compatibility/opengl3，关闭垂直同步、不限帧；固定种子7的染色展示盘，每条件预热90帧、采样240帧。记录 `frame_post_draw` 间隔，包含引擎、驱动与调度开销，**不是GPU计时或Shader独占耗时**。

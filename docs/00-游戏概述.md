# 游戏概述 (Game Overview)

**项目名称：** 矩阵连线 (Project: Matrix Link)  
**版本：** 1.0 (MVP)  
**类型：** 益智策略 / Roguelike / 空间管理  
**平台：** PC (Godot 4)，未来计划移动端  
**开发引擎：** Godot 4  
**开发语言：** GDScript  

---

## 核心体验 (Core Experience)

在极度压缩的空间内，通过"消除"来整理内存，对抗系统熵增。

玩家扮演一名黑客，在一个 9x9 的老式 CRT 终端界面上进行"内存清理"。不仅要通过传统的"五子连珠"消除数据球得分，还需要在有限的棋盘格子上"建设"倍率塔、陷阱和工厂。

**空间是唯一的资源**。买道具会变强，但也会挤占生存空间。你必须在"填满棋盘（死机）"之前，通过构筑连锁反应，破解 8 层防火墙。

---

## 游戏特色 (Key Features)

1. **空间管理核心玩法**：每个建筑都占用空间，需要权衡收益与空间成本
2. **肉鸽构筑系统**：通过建筑组合创造强大的连消引擎
3. **连锁反应机制**：消除触发冲击波，解锁宝箱、激活黑市、震碎故障
4. **渐进式难度**：安全等级随时间提升，生成更多威胁
5. **CRT 终端美学**：复古赛博风格，扫描线效果，霓虹色彩

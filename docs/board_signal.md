# 棋盘局部信号试验（#31）

设置 / F1 →「棋盘信号效果」，默认开启并独立保存偏好，与动态背景并排。低特效优先关闭；关闭/开启不改变棋盘、候选、总分和随机流。#109背景已按作者授权阶段性合并，但作者并未完全满意，仍在O3 #9保留打磨反馈；本片不将其记为最终美术验收。

本片试验轻扫描纹理、彩色棋子边缘描光、每10秒通过一次的窄扫描带。扫线/爆破开始时增加一次有上限的局部扫描带响应，0.9秒衰减。明亮主题较弱、深色主题较强；不做UV位移、色差错位或全屏闪光，保留已验收的纯色格子。参数为首轮可调值，是否保留/调整仍待作者试玩。

## 实现边界

`gameplay/presentation/board_signal_effect/`保存可复用场景、同名入口脚本、Shader及只读`BoardSignalConfig`，由GameTheme组合。BoardView传入棋盘矩形、主题、开关/低特效与扫线/爆破的表现通知；不另查规则、不计分、不使用随机、不追加演出等待。

效果节点用screen texture读取棋盘下方已绘制图像，输出限定在棋盘矩形。层级15位于棋子/扫线之上、得分漂字20之下；HUD、卡牌、tooltip在独立更高CanvasLayer，不参与处理。`mouse_filter=IGNORE`，不接收鼠标，棋盘变换与碰撞范围不变。低特效或关闭时隐藏节点，停止处理及屏幕读取；材质ready时复制，A/B与场景模板隔离，配置不写运行状态。

扫描相位使用显式PAUSABLE的独立时钟：暂停/选卡冻结，快放不改变速度；重建/重试/清理旧表现时复位；切换主题重新应用配色与相位。原导演的完成屏障、跳过与文件记录协议保持原入口。

## 实机证据与 review

[18秒演示](screenshots/board_signal/signal_demo.mp4)：两主题各9秒，固定0.1秒视觉步长、10FPS编码，按配置速度播放，第4秒注入一次表现响应。固定种子7的`fixture_line_cross`用于观察五色、普通/爆破/引信/行扫/列扫、选中格与路径，不作为真人平衡样本。对照时动态背景关闭，避免混入背景运动。

1280×720开/关截图的像素差异边界在两主题均为`(541,113)～(1046,618)`，完全位于棋盘内；其外HUD像素相同。已人工查看静态截图，动效舒适度及长局读盘仍待作者验收。

建议试玩：两主题分别开关对照，观察五色/形状、特殊标记、选中与路径；实际移动、行列清除/连锁爆破；三选一打开设置、关闭低特效后返回；切换快放、暂停及重试。重点判断扫描纹理是否干扰辨色，扫描带是否像无意义装饰，是否值得保留。不要把自动回归通过当成风格已满意。

验证：Godot4.7.2编辑器导入无脚本解析/编译错误；背景、主题、棋盘信号、布局、设置和扫线视觉38项通过。最终扩充两开关的中英小视口布局检查后，棋盘信号、布局、输入缓冲、奖励演出20项通过。覆盖开关不改快照/变换/拾取、低特效优先、暂停/快放、材质与模板隔离、偏好保存、真实扫线精确回放及重试复位。

## 桌面帧间隔基线

Windows/i7-9700KF/RTX2070，Godot4.7.2 Compatibility/opengl3，关闭垂直同步、不限帧；每条件预热90帧、采样240帧。复用既有采集工具增加`--board-signal`模式，背景关闭，测固定特殊棋盘。测量`frame_post_draw`总间隔，**不是Shader独占GPU耗时**。

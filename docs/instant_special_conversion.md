# 即时特殊棋转化（#101）

三张即时牌：爆壳改装、横扫改装、纵扫改装。先按稀有、基础权重5、第3次奖励起可选试调；不代表已完成平衡验收。

每张牌把随机至多3枚无能力普通棋转为对应特殊棋，候选生成时无放回锁定ID。保留颜色、位置、ID、占格和后续ID计数；不足3枚全部转化，无目标不进入候选。不覆盖引信、已有特殊棋或幽灵棋。不立即消除、得分或检查五连，不解锁自然补给。

转化允许多爆破手共存。自然补给和“爆壳手登场”的单枚限制保持原规则：已有核心时不追加。对应本局升级对转化棋生效，但转化不替代供给升级的前置条件。主动激活仍由对应卡共享每局3次，连锁不额外扣；新转化不补次数。

`TransformMaterialEffect`只消费上下文快照并冻结目标；`AbilityResolver`完整预检后通过`BoardRules`修改content并逐枚安装独立能力实例。目标消失、重复、带能力或事件预算不足时，整批拒绝且不消耗奖励、行动和随机数。动画消费复制的`transformed`结果，复用原棋子节点，不修改规则。

记录新增可选`SkillAcquired.transformed`，采集分开记录转化，不计新增/消除或得分。结果观看兼容缺省字段；精确命令回放使用`run-commands-v34-special-conversion`，不支持旧规则跨版本重算。单局时长采集保持原口径。

## 编辑器试玩

1. 启动游戏，关闭开始页后按F12，打开固定转化三选一。
2. 选择一种改装，确认最多3枚普通棋只改变能力标记，颜色和位置不变。已有引信和蓝色爆破手不变。
3. 再按F12可重新选择另两种。示例不预装主动技能，转化本身不授予主动激活。
4. 正常局中结合既有主动、跨度、十字和得分技能观察连携；已有主动次数不会因改装恢复。

F12是固定规则示例，不作为真实平衡采样。自动测试覆盖三类0/1/2/3/更多材料、事务拒绝、实例隔离、多核心和行→列→爆破连锁、真实JSONL回放、采集分类、原节点演出、低特效及只读结果观看。真人手感仍待作者试玩。

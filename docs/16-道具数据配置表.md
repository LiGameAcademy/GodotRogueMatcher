## 一、设计原则

### 核心原则：空间即资源

每个道具占用 1 格棋盘空间。玩家需要在"收益"与"空间成本"之间做出权衡。

### 道具分类

| 类型 | 说明 | 触发时机 |
|------|------|---------|
| **建筑 (Building)** | 放置后持续生效 | 回合开始 / 消除时 |
| **遗物 (Relic)** | 放置后持续生效 | 全局被动 |

### 效果类型

| 类型 | 说明 | 叠加方式 |
|------|------|---------|
| **倍率 (Multiplier)** | 分数乘以系数 | 乘法叠加 |
| **加成 (Bonus)** | 分数增加固定值 | 加法叠加 |
| **功能 (Function)** | 特殊效果 | 独立生效 |

## 三、道具详细设计

### 1. 棱镜塔 (Prism Tower)

| 字段 | 值 |
|------|-----|
| **ID** | `prism_tower` |
| **名称** | 棱镜塔 |
| **名称(英)** | Prism Tower |
| **稀有度** | COMMON (普通) |
| **类型** | Building (建筑) |
| **占用空间** | 1 格 |
| **图标描述** | 彩色三角棱镜，折射光线 |

#### 效果设计

| 触发时机 | 条件 | 效果 | 数值 |
|---------|------|------|------|
| 消除检测 | 棱镜塔参与消除 | 该次消除得分 | x2 |

#### 效果说明

- 棱镜塔被视为"万能色"，可与任意颜色组成连线
- 棱镜塔参与消除时，该次消除的**基础分**乘以 2
- 多个棱镜塔叠加：**乘法**，如 2 个棱镜塔 = x4

#### 策略价值

- **高** — 核心得分道具，直 接提升消除价值
- 优先放置在容易形成连线的位置

#### 伪代码实现

```gdscript
# 消除得分计算时
if cell.piece is ChessPiece and cell.piece.item_data.id == "prism_tower":
    match_score *= 2  # 棱镜塔参与的消除得分 x2
```

### 2. 增幅器 (Amplifier)

| 字段 | 值 |
|------|-----|
| **ID** | `amplifier` |
| **名称** | 增幅器 |
| **名称(英)** | Amplifier |
| **稀有度** | COMMON (普通) |
| **类型** | Building (建筑) |
| **占用空间** | 1 格 |
| **图标描述** | 圆形扩散波纹，能量放大 |

#### 效果设计

| 触发时机 | 条件 | 效果 | 数值 |
|---------|------|------|------|
| 消除时 | 消除发生在增幅器周围 8 格 | 该次消除基础分 | +100% |

#### 效果说明

- 增幅器自身不参与连线
- 周围 8 格（上下左右 + 4 个斜角）发生的消除，基础分 +100%
- 多个增幅器叠加：**加法叠加**，如 2 个增幅器 = +200%

#### 策略价值

- **中等** — 区域增益，放置在棋盘中心效果更好
- 可与棱镜塔配合使用

#### 伪代码实现

```gdscript
# 获取增幅器周围的单元格
func get_amplifier_bonus(board, amplifier_cell) -> float:
    var bonus: float = 0.0
    for neighbor in board.get_neighbors(amplifier_cell, 1):  # 8格范围
        if board.get_cell(neighbor).piece:
            # 检查该位置是否有增幅器
            if board.get_cell(neighbor).piece.item_data.id == "amplifier":
                bonus += 1.0  # +100%
    return bonus  # 返回加法叠加的倍率（1.0 = 100%）
```

### 3. 染色工厂 (Dye Station)

| 字段 | 值 |
|------|-----|
| **ID** | `dye_station` |
| **名称** | 染色工厂 |
| **名称(英)** | Dye Station |
| **稀有度** | COMMON (普通) |
| **类型** | Building (建筑) |
| **占用空间** | 1 格 |
| **图标描述** | 颜料罐，色彩滴落 |

#### 效果设计

| 触发时机 | 条件 | 效果 | 数值 |
|---------|------|------|------|
| 回合开始 | 染色工厂存在 | 上下左右 4 格中随机 1 个球染色 | 指定颜色 |

#### 效果说明

- 每回合开始时，自动将周围 4 格中的 1 个随机球染成**指定颜色**
- 目标颜色在放置时选择（5 种颜色之一）
- 如果周围没有球，则效果不触发

#### 策略价值

- **中等** — 主动创造连线机会
- 放置在球密度较高的区域效果更好

#### 伪代码实现

```gdscript
# 回合开始时
func _on_turn_started():
    for dye_station in placed_items:
        if dye_station.item_data.id == "dye_station":
            var target_color = dye_station.dye_color  # 放置时指定的颜色
            var neighbors = board.get_adjacent_cells(dye_station.cell, 4)
            var random_ball = neighbors.filter(func(c): return c.piece != null).pick_random()
            if random_ball:
                random_ball.piece.piece_type = target_color
```

| **名称(英)** | Ether Totem |

| **类型** | Relic (遗物) |
| **占用空间** | 1 格 |
| **图标描述** | 水晶柱，散发红光 |

#### 效果设计

| 触发时机 | 条件 | 效果 | 数值 |
|---------|------|------|------|
| 消除时 | 消除涉及红球 | 该次消除得分 | x1.5 |

#### 效果说明

- 全局被动效果，所有涉及红球的消除得分 x1.5
- 多个以太图腾叠加：**乘法**，如 2 个 = x2.25

#### 策略价值

- **高（特定情况）** — 如果能围绕红球构建战略
- 适合与棱镜塔配合

#### 伪代码实现

```gdscript
# 消除得分计算时
func calculate_match_score(match_info):
    var base_score = match_info.base_score
    var multiplier = 1.0

    # 检查是否涉及红球（piece_type == 0）
    if match_info.piece_types.has(0):  # 红球
        multiplier *= 1.5  # 以太图腾效果

    return base_score * multiplier
```

### 6. 空间压缩机 (Space Compressor)

| 字段 | 值 |
|------|-----|
| **ID** | `space_compressor` |
| **名称** | 空间压缩机 |
| **名称(英)** | Space Compressor |
| **稀有度** | RARE (稀有) |
| **类型** | Building (建筑) |
| **占用空间** | 1 格 |
| **图标描述** | 压缩方块，次元扭曲 |

#### 效果设计

| 触发时机 | 条件 | 效果 | 数值 |
|---------|------|------|------|
| 生成球时 | 每回合生成新球 | 新球有几率成为幽灵球 | 20% |

#### 效果说明

- 幽灵球不占实际空间，可与其他球重叠
- 幽灵球正常参与连线，但不影响棋盘空间
- 幽灵球被消除时，额外计入得分（因为"不占空间"所以更赚）

#### 策略价值

- **高** — 缓解空间压力
- 后期空间紧张时价值更高

#### 幽灵球视觉

- 半透明显示
- 带有紫色轮廓

#### 伪代码实现

```gdscript
# 生成球时
func spawn_piece(board):
    var is_ghost = false
    for compressor in placed_items:
        if compressor.item_data.id == "space_compressor":
            if randf() < 0.2:  # 20%
                is_ghost = true
                break

    var piece = create_piece()
    piece.is_ghost = is_ghost
    return piece
```

### 三选一生成规则

1. 根据当前等级确定稀有度概率
2. 随机抽取 3 个道具有效的候选池（同一类型只出现一次）
3. 确保 3 个选项类型不完全相同
4. 如果候选池不足 3 个，填充空选项

## 五、效果叠加规则

### 倍率叠加（乘法）

用于：棱镜塔、以太图腾

```
最终倍率 = 倍率1 × 倍率2 × 倍率3 ...
例：棱镜塔(x2) × 以太图腾(x1.5) = x3
```

### 加成叠加（加法）

用于：增幅器、能量核心

```
最终加成 = 加成1 + 加成2 + 加成3 ...
例：增幅器(+100%) + 能量核心(+50%) = +150%
```

### 综合计算顺序

```
最终得分 = (基础分 × 棱镜塔倍率 + 固定加成) × 增幅器加成 × 以太图腾倍率
```

## 六、道具放置规则

### 放置位置选择

1. **随机空位** — 从所有空位中随机选择
2. **避开边缘** — 优先选择 3x3 中心区域（减少死像素堵塞边缘）
3. **避开已有道具** — 确保不与已有道具重叠

### 放置限制

- 所有道具均可放置在任意空位
- 无特殊放置限制（如需要特定颜色等）

### 放置动画

- 从棋盘上方落入
- 缩放弹出（0 → 1，300ms，ease-out）
- 粒子特效（光芒四射）

# 升级系统设计 (Level Up System Design)

---

## 一、设计理念

**核心体验：** 类似《Vampire Survivors》的升级系统

- **触发方式：** 达到分数里程碑，自动触发升级
- **选择方式：** 三选一界面，玩家选择道具
- **放置方式：** 道具自动出现在棋盘随机位置
- **策略深度：** 通过选择不同道具构建独特的构筑

---

## 二、升级触发机制

### 1. 分数里程碑

#### 1.1 里程碑设置
- **初始里程碑：** 500 分
- **里程碑递增：** 每次递增 50%（或固定值）
- **示例：** 500 → 750 → 1125 → 1688 → 2532...

#### 1.2 计算公式
```
下一个里程碑 = 当前里程碑 × 1.5
或
下一个里程碑 = 当前里程碑 + 固定值（如 500）
```

#### 1.3 里程碑列表（建议）
| 等级 | 所需分数 | 累计分数 |
|------|----------|----------|
| Lv.1 | 500 | 500 |
| Lv.2 | 750 | 1250 |
| Lv.3 | 1125 | 2375 |
| Lv.4 | 1688 | 4063 |
| Lv.5 | 2532 | 6595 |
| ... | ... | ... |

### 2. 触发流程

1. **检测触发：** 每次消除后检查是否达到里程碑
2. **暂停游戏：** 暂停游戏时间（可选）
3. **显示界面：** 显示三选一界面
4. **玩家选择：** 玩家点击选择道具
5. **放置道具：** 道具自动放置在棋盘随机位置
6. **继续游戏：** 恢复游戏

## 三、三选一界面设计

### 1. 界面布局

```
┌─────────────────────────────────────┐
│          LEVEL UP!                   │
│         等级提升！                    │
├─────────────────────────────────────┤
│                                     │
│   [道具1]    [道具2]    [道具3]      │
│   图标       图标       图标          │
│   名称       名称       名称          │
│   描述       描述       描述          │
│                                     │
└─────────────────────────────────────┘
```

### 2. 道具卡片设计

#### 2.1 卡片内容
- **图标：** 64x64 像素，赛博风格
- **名称：** 道具名称（中英文）
- **描述：** 简短的效果说明
- **稀有度标识：** 边框颜色（普通/稀有/史诗）

#### 2.2 交互方式
- **悬停：** 卡片放大，显示详细信息
- **点击：** 选择该道具
- **键盘：** 1/2/3 数字键快速选择（可选）

### 3. 道具生成规则

#### 3.1 物品池系统
- **普通池：** 基础道具（棱镜塔、增幅器等）
- **稀有池：** 强力道具（空间压缩机等）
- **史诗池：** 特殊道具（特殊效果）

#### 3.2 生成规则
- **3 个道具：** 从不同稀有度池中随机选择
- **保证多样性：** 确保 3 个道具类型不同
- **避免重复：** 已获得的道具降低出现概率（可选）

## 四、道具自动放置

### 1. 放置规则

#### 1.1 位置选择
- **随机空位：** 从棋盘所有空位中随机选择
- **避免边缘：** 优先选择中心区域（可选）
- **避免重叠：** 确保位置可用

#### 1.2 放置动画
- **出现方式：** 
  - 从上方落下（推荐）
  - 闪烁出现
  - 缩放弹出
- **动画时长：** 0.3-0.5 秒
- **音效：** 道具放置音效

### 2. 放置验证

```gdscript
func place_item_randomly(board: Board, item: ItemData) -> bool:
    # 获取所有空位
    var empty_cells = board.get_empty_cells()
    if empty_cells.is_empty():
        return false
    
    # 随机选择空位
    var random_cell = empty_cells[randi() % empty_cells.size()]
    
    # 放置道具
    return place_item(board, random_cell, item)
```

## 五、道具系统简化

### 1. 道具分类（简化版）

#### 1.1 建筑类（占用空间）
- **棱镜塔：** 万能色，得分 x2
- **增幅器：** 周围消除 +100%
- **染色工厂：** 每回合染色
- **空间压缩机：** 20% 几率生成幽灵球

#### 1.2 遗物类（占用空间，全局效果）
- **以太图腾：** 红球消除 x1.5
- **能量核心：** 所有消除 +50%
- **时间加速器：** 移动速度 +20%

#### 1.3 被动效果（不占空间）
- **连击大师：** 连锁倍率 +25%
- **空间感知：** 初始可用区域 +1 格
- **幸运星：** 生成时 10% 几率额外生成 1 个球

### 2. 道具效果实现

#### 2.1 建筑效果
- 建筑占用空间，提供持续效果
- 效果在回合开始或消除时触发

#### 2.2 遗物效果
- 遗物占用空间，提供全局被动效果
- 效果持续生效

#### 2.3 被动效果
- 不占用空间，直接修改游戏参数
- 效果全局生效

## 六、优势分析

### 1. 简化设计
- ✅ **无需商店系统：** 减少 UI 复杂度
- ✅ **无需金币系统：** 简化经济系统
- ✅ **自动放置：** 减少操作复杂度

### 2. 增强体验
- ✅ **节奏感强：** 定期升级，保持兴奋
- ✅ **策略选择：** 三选一增加决策深度
- ✅ **随机性：** 道具随机出现增加重玩性

### 3. 符合肉鸽体验
- ✅ **类似 Survivors：** 熟悉的升级体验
- ✅ **构筑深度：** 通过选择构建独特构筑
- ✅ **空间管理：** 道具占用空间，需要权衡

        next_milestone = int(next_milestone * 1.5)

## 八、未来扩展

### 1. 道具升级
- 相同道具可以升级（如棱镜塔 Lv.1 → Lv.2）
- 升级后效果增强

### 2. 道具组合
- 特定道具组合产生额外效果
- 套装系统

### 3. 道具移除
- 允许移除已放置的道具（消耗资源或特殊道具）

## 九、与商店系统对比

### 商店系统（原设计）
- ❌ 需要金币系统
- ❌ 需要商店 UI
- ❌ 需要拖拽操作
- ❌ 需要手动放置
- ✅ 玩家控制更强

### 三选一升级系统（新设计）
- ✅ 无需金币系统
- ✅ 界面更简单
- ✅ 操作更简单
- ✅ 自动放置
- ✅ 节奏感更强
- ✅ 更符合肉鸽体验

---

## 十、总结

**新设计的优势：**
1. ✅ **简化开发：** 减少系统复杂度
2. ✅ **增强体验：** 更符合肉鸽游戏节奏
3. ✅ **易于扩展：** 可以轻松添加新道具
4. ✅ **策略深度：** 三选一增加决策乐趣

**建议：** 采用三选一升级系统，更适合 MVP 阶段和肉鸽体验。

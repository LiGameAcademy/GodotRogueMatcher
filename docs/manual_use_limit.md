# 主动卡每局三次（#103）

作者确认先试调次数限制。主动爆破、主动扫线各3次/局，保持稀有、权重10及既有解锁前置。

- 行、列共用主动扫线卡的3次，不是每枚棋子3次。
- 成功提交主动命令扣1次，空爆/空扫也扣；后代连携不扣次数。
- 第四次拒绝并保留来源，不移动、补棋、得分或推进压力。不合法、过期、忙碌、预算预检拒绝不扣；相同命令重发复用既有结果。
- 耗尽后仍可移动和参加匹配；匹配、爆炸或清理移除仍触发固有离场效果。
- 暂停、重建视图、过关、通关后继续均不恢复；真正新局重置。

`SkillDefinition.manual_use_limit`提供只读限额，`RunState.manual_uses_used`拥有各卡已用次数。只有RunController通过全部预检后的主动命令提交点递增；Resolver的固有能力和后代不扣次数。HUD横卡及棋子提示消费同一状态；机器人不枚举耗尽命令。

规则版本`run-commands-v32-manual-use-limit`。快照、命令前后记录、退出观察保存已用次数，旧版本精确回放明确拒绝。补齐主动扫线完整行动采集；`command_resolved`附加`manual_uses_before/after`，保留既有采集协议与单局时长。

## 作者试玩

在编辑器运行游戏，按 **Alt+F11**。依次双击第1列第1行、第1列第3行、第5列第5行的扫线手，横卡应从3/3降至0/3。再双击第1列第7行：棋子保留，没有第四次行动/补棋。悬停显示次数耗尽，仍可移动、被消除触发。该固定盘仅验证规则，不作为平衡样本。

Ctrl+F11仍是十字连携固定盘：双击左侧行扫手，行→列→爆破手等连携只扣1次主动扫线。实际游玩再验证3次机会是否足够，当前不进一步调整稀有度或权重。

## 验证范围

`test_manual_use_limit.gd`覆盖两卡独立、行列共享、三次后拒绝、空放、重发/过期/预算、耗尽后的自然移除、连携只扣根及真实JSONL回放与采集。场景测试覆盖Alt+F11、暂停/重建、拒绝后继续操作、棋子tooltip；HUD测试覆盖0/3卡仍保留及中英显示。续玩测试验证次数不恢复。

## 规则与试调值

- 新增优秀卡“扫线收获”：任一行/列补给解锁后可选，最高3级、基础权重20。每实际直接清除一枚，额外得分+2/级。
- 在`floor(基础分 × 全局倍率 + 既有额外分 + 清除枚数 × 2 × 等级)`中结算。来源不计、交叉去重、空扫0分；只给`line_clear`事件，普通五连、林道开辟等即时清理与爆炸后代不套用本奖励。
- 主动、固有离场、单轴与十字共用此结算入口。每枚2分、三级及稀有度/权重是首轮试调，不代表平衡实测。
- 作者反馈收获获取难度应低于主动扫线，本片将收获基础权重10→20；主动扫线保持稀有、权重10、每局3次。两者前置相同，抽选仍随机，不保证具体取得次序。配置指纹区分这次数值调整，不改抽选算法。
- 染色六卡保留，基础权重10→3；这不是“出现率3%”。实际候选仍受稀有度、资格、构筑与既有抽选策略影响，玩家界面不显示权重。
- 前两次奖励仍只有首个生成槽保底启动。集合改为爆壳手/行清除手/列清除手；任意供给解锁后停止保底，另外两种启动仍可从普通池出现。染色不再作为启动，也移除专属探索优待，普通池仍可抽到。
- 保留既有爆破探索、压力救场与其他抽选算法。本片不实施0.0.3的技能随机系统重设，不新增行列补给升级或即时转化。

# 关卡进度系统 (Level Progression System)

---

## 一、关卡结构 (Level Structure)

### 1. 关卡数量
- **总关卡数：** 8 层防火墙 (Ante 1-8)
- **关卡命名：** Ante 1, Ante 2, ..., Ante 8
- **关卡主题：** 每层有不同的视觉主题（未来扩展）

### 2. 关卡目标

#### 2.1 胜利条件
- **目标分数：** 达到或超过目标分数
- **目标分数表：**
  - **Ante 1:** 1,000 分
  - **Ante 2:** 3,000 分
  - **Ante 3:** 8,000 分
  - **Ante 4:** 20,000 分
  - **Ante 5:** 50,000 分
  - **Ante 6:** 120,000 分
  - **Ante 7:** 300,000 分
  - **Ante 8:** 750,000 分
- **分数增长：** 指数增长（约 2.5 倍）

#### 2.2 失败条件
- **空间不足：** 棋盘填满，且无法生成新球（内存溢出）
- **超时：** 安全等级过高，无法继续（可选）

---

## 二、关卡流程 (Level Flow)

### 1. 关卡开始

#### 1.1 初始化
- **重置棋盘：** 清空所有球（保留建筑）
- **重置分数：** 分数归零（或保留部分分数）
- **重置回合：** 回合数归零
- **重置安全等级：** 安全等级重置为 Lv.1
- **保留内容：** 
  - 建筑布局
  - 金币（可选）
  - 遗物效果

#### 1.2 显示信息
- **关卡名称：** 显示当前关卡（如 "Ante 3"）
- **目标分数：** 显示目标分数
- **当前分数：** 显示当前分数（0）
- **进度条：** 显示分数进度

### 2. 关卡进行

#### 2.1 游戏循环
- 玩家进行消除和构筑
- 分数逐渐增加
- 安全等级逐渐提升
- 威胁逐渐增加

#### 2.2 进度显示
- **分数进度：** 显示当前分数 / 目标分数
- **进度条：** 可视化进度
- **剩余回合估算：** 根据当前效率估算（可选）

### 3. 关卡完成

#### 3.1 完成条件检测
```gdscript
func check_level_complete():
    if current_score >= target_score:
        complete_level()
```

#### 3.2 完成奖励
- **清空球：** 清空所有普通球（保留建筑）
- **金币奖励：** 根据剩余空位数给予金币
  - 计算公式：`奖励金币 = 剩余空位数 × 2`
- **进入下一层：** 自动进入下一关卡

#### 3.3 完成动画
- **胜利效果：** 屏幕闪烁、粒子效果
- **音效：** 胜利音效
- **显示奖励：** 显示获得的金币数

### 4. 关卡失败

#### 4.1 失败检测
```gdscript
func check_level_failed():
    if get_available_cells() <= 0 and cannot_spawn_balls():
        fail_level()
```

#### 4.2 失败处理
- **失败动画：** 蓝屏效果（CRT 风格）
- **失败统计：** 显示本局数据
- **重试选项：** 提供重试按钮

## 三、关卡间进度 (Inter-Level Progression)

### 1. 保留内容

#### 1.1 建筑保留
- **保留所有建筑：** 建筑布局完全保留
- **保留效果：** 建筑效果继续生效
- **策略意义：** 鼓励玩家构建长期构筑

#### 1.2 金币保留（可选）
- **选项1：** 完全保留
- **选项2：** 保留 50%
- **选项3：** 不保留（当前设计）

#### 1.3 遗物保留
- **保留所有遗物：** 遗物效果继续生效

### 2. 重置内容

#### 2.1 棋盘重置
- **清空球：** 移除所有球
- **清空威胁：** 移除死像素、粘滞扇区等
- **清空交互实体：** 移除宝箱、黑市等

#### 2.2 状态重置
- **分数重置：** 分数归零
- **回合重置：** 回合数归零
- **安全等级重置：** 安全等级重置为 Lv.1

## 四、难度曲线 (Difficulty Curve)

### 1. 早期关卡 (Ante 1-3)

#### 1.1 特点
- **目标分数：** 较低（1k - 8k）
- **安全等级：** 提升较慢
- **威胁：** 较少
- **目标：** 让玩家熟悉游戏机制

#### 1.2 设计重点
- **教学：** 引导玩家学习基本操作
- **容错：** 允许玩家犯错
- **成就感：** 让玩家容易达成目标

### 2. 中期关卡 (Ante 4-6)

#### 2.1 特点
- **目标分数：** 中等（20k - 120k）
- **安全等级：** 提升正常
- **威胁：** 逐渐增加
- **目标：** 考验玩家策略能力

#### 2.2 设计重点
- **策略深度：** 需要更深入的策略思考
- **空间管理：** 空间压力逐渐增加
- **构筑优化：** 需要优化构筑体系

### 3. 后期关卡 (Ante 7-8)

#### 3.1 特点
- **目标分数：** 很高（300k - 750k）
- **安全等级：** 提升很快
- **威胁：** 密集
- **目标：** 极限挑战

#### 3.2 设计重点
- **极限挑战：** 考验玩家极限能力
- **完美构筑：** 需要近乎完美的构筑
- **运气因素：** 适当的随机性增加挑战

## 五、关卡数据 (Level Data)

### 1. 关卡配置
```gdscript
class_name LevelData extends Resource

@export var level_id: int  # 1-8
@export var target_score: int  # 目标分数
@export var initial_security_level: int = 1  # 初始安全等级
@export var security_level_increase_interval: int = 15  # 安全等级提升间隔
@export var theme: String  # 关卡主题（未来扩展）
```

### 2. 关卡管理器
```gdscript
# LevelManager.gd
extends Node

var current_level: int = 1
var current_score: int = 0
var target_score: int = 1000

var level_data: Array[LevelData] = []

func start_level(level_id: int):
    var data = level_data[level_id - 1]
    current_level = level_id
    target_score = data.target_score
    current_score = 0
    # 初始化关卡...

func check_level_complete() -> bool:
    return current_score >= target_score

func complete_level():
    # 计算奖励
    var reward = calculate_reward()
    # 进入下一层
    if current_level < 8:
        start_level(current_level + 1)
    else:
        # 游戏通关
        game_complete()
```

## 六、进度保存 (Progress Saving)

### 1. 保存内容
- **当前关卡：** 保存当前关卡数
- **最高关卡：** 保存达到的最高关卡
- **关卡状态：** 保存当前关卡的游戏状态（可选）

- **新游戏：** 从第一关开始

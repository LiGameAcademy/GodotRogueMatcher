## 四、本地化管理器 (Localization Manager)

### 1. LocalizationManager 实现

```gdscript
# LocalizationManager.gd (Autoload)
extends Node

signal language_changed(language: String)

var current_language: String = "zh_CN"
var translations: Dictionary = {}

const SUPPORTED_LANGUAGES = ["zh_CN", "en_US"]
const DEFAULT_LANGUAGE = "zh_CN"

func _ready():
    # 从设置加载语言
    current_language = load_language_from_settings()
    load_translations(current_language)

func load_translations(language: String):
    var file_path = "res://assets/localization/" + language + ".json"
    var file = FileAccess.open(file_path, FileAccess.READ)
    if file == null:
        print("错误：无法加载本地化文件：", file_path)
        # 回退到默认语言
        if language != DEFAULT_LANGUAGE:
            load_translations(DEFAULT_LANGUAGE)
        return
    
    var json_string = file.get_as_text()
    file.close()
    
    var json = JSON.new()
    var parse_result = json.parse(json_string)
    if parse_result != OK:
        print("错误：无法解析本地化文件：", file_path)
        return
    
    translations = json.data
    language_changed.emit(language)

func set_language(language: String):
    if language in SUPPORTED_LANGUAGES:
        current_language = language
        load_translations(language)
        save_language_to_settings(language)
    else:
        print("警告：不支持的语言：", language)

func tr(key: String) -> String:
    # 支持嵌套键，如 "ui.menu.title"
    var keys = key.split(".")
    var value = translations
    
    for k in keys:
        if value is Dictionary and value.has(k):
            value = value[k]
        else:
            # 键不存在，返回键本身
            print("警告：本地化键不存在：", key)
            return key
    
    if value is String:
        return value
    else:
        return key

func trf(key: String, args: Array) -> String:
    # 格式化字符串，支持参数替换
    var text = tr(key)
    for i in range(args.size()):
        text = text.replace("{" + str(i) + "}", str(args[i]))
    return text
```

### 2. 使用示例

```gdscript
# 在代码中使用
var title = LocalizationManager.tr("ui.menu.title")
var description = LocalizationManager.trf("item.prism_tower.description", [multiplier])

# 在 UI 中使用
$Label.text = LocalizationManager.tr("ui.menu.title")
```

## 六、UI 自动本地化 (Automatic UI Localization)

### 1. 自动本地化节点

```gdscript
# LocalizedLabel.gd
extends Label

@export var translation_key: String = ""

func _ready():
    if translation_key != "":
        text = tr(translation_key)
    
    # 监听语言变化
    LocalizationManager.language_changed.connect(_on_language_changed)

func _on_language_changed(language: String):
    if translation_key != "":
        text = tr(translation_key)
```

### 2. 使用方式

在场景中：
- 添加 `LocalizedLabel` 节点
- 设置 `translation_key` 属性（如 "ui.menu.title"）
- 文本会自动根据当前语言更新

## 九、本地化最佳实践 (Localization Best Practices)

### 1. 文本设计
- **避免硬编码：** 所有文本都使用本地化键
- **上下文清晰：** 键名清晰表达上下文
- **参数化：** 使用格式化字符串支持参数

### 2. 键命名规范
- **格式：** `模块.子模块.具体项`
- **示例：** `ui.menu.title`, `item.prism_tower.name`
- **一致性：** 保持命名一致性

### 3. 文本长度
- **考虑UI空间：** 不同语言文本长度不同
- **UI适配：** UI 设计要考虑文本长度变化
- **截断处理：** 处理文本过长的情况

### 4. 特殊字符
- **支持特殊字符：** 确保支持各种语言的特殊字符
- **字体支持：** 确保字体支持所有字符

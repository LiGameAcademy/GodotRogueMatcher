# #160 接管成本分项与最小去重

2026-10-30；基线 #224 合并 `0442d8635647cdbc9ad03c35a7e1cae7c08be380`。本片只处理恢复末尾的重复UI工作，不改规则、存储、父链或后台重建。

用实际场景的测试派生脚本包围真实`super`调用，分别测Board激活/视图重建、Game恢复接线、采集配置/绑定/flush。没有复制另一套接管实现，也没有改生产场景绑定；wrapper仅由专用probe运行时注入，采集环境标为automated_integration。相同正常局95行动887记录存档、RTX2070/OpenGL3.3、1280×720，两次独立APPDATA。

生产改动只有两项：

1. Board同步接管期间发出的两次HUD刷新由Game暂缓，末尾`Hud.bind_checkpoint`一次完整刷新。只读`is_adopting()`对应既有`_taking_over`区间，包含无await的Board.adopt；取消/加载失败/旧局正常更新不进入该guard，不跳过其他Board信号。
2. 恢复后不再遍历整套场景重刷同一主题。View.configure/show_piece、BuildList.show_state会为新格子/棋子/卡片使用已存主题，其余UI仍是已上主题的原实例。未修改主题Resource、材质复制或场景调参。

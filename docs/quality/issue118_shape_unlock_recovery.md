# #118 第三片：真实解锁、立即扫描与空盘恢复

2026-10-21。前置 PR #171 已复审通过并合并到 develop/0.0.3（be0b01e）。本片实现已确认 U/L/R 契约，解锁配方仅放在显式验收 profile，不加入生产 SkillOfferGenerator.CATALOG，也不决定正式形状名单、稀有度、权重或配方。

## 权威状态与入口

ShapeUnlockState 由本局 BoardRules 独占，保存稳定形状身份、模板副本、取得 root，以及恢复过程/批次/规则身份。构造时原型开关仍与成功取得分开。UnlockShapeEffect 经真实发牌、冻结目标、ChooseSkillCommand、根前检、SkillRules 提交，先启用形状，再用当前全部已启用规则全盘收集、合并、冻结计分和移除。无匹配仍取得成功。

同形状重复配方按形状身份过滤，根组合中重复或已失效的解锁前置在首叶前拒绝；不先发前叶收益再发现重复。已成功命令仍由原身份幂等处理，不能重复取得、扫描、消费、后代或恢复。未消费旧候选失效时保留原奖励及其他合法候选，沿已有一次系统重建政策处理，不新增主动刷新。

独立解锁在自身边界释放后代，嵌套解锁只即时兑现匹配，最外层组合结束才处理爆破/扫线/染色等后代。固定目标失效沿 SKIP_INVALID/REJECT；动态后叶只从新盘面选择。真正异常保留已提交部分并锁定 ERROR，不承诺整段回滚。

## 恢复边界与一次预算

解锁叶不出生。RunController.advance 先处理待选奖励和原继续义务，只在 idle/after_spawn、即将返回操作的安全边界检查恢复。最终非空则关闭恢复过程；最终为空才兑现当前预告一次。普通剩余批次先完成，不叠加恢复。

恢复消费当前锁定的数量、颜色、类型和顺序，逐枚按真实空位出生并处理匹配/后代；有限加减量生效但不扣剩余次数。它有独立批次和内部规则 action ID，保留来源解锁 root，避免沿用旧 root 的一次触发门禁；不增加有效移动、主动激活、回合、阶段行动或升压计数。整批后代完成后收束该 root 的连锁收益与修正，清理统计，不伪造普通批次前窗口或玩家行动奖励。

恢复过程贯穿其出生触发的连续奖励。不能在出生批次刚结束时关闭 pending，否则后续奖励中的另一次解锁会重新安装预算。只有真正准备返回操作、奖励与继续义务均完成且棋盘仍非空，才关闭过程。若期间再次全清，保留已提交分数和令牌，诊断 empty_board_after_recovery、锁定输入和自动推进，不启动第二批，也不冒充满盘失败/通关。

开发中用 R08 失败测试真实复现了第二批误启动（batch 2、6 枚出生），修复后保持 batch 1、3 枚。另用显式 200 分夹具和真实恢复匹配跨越累计门槛 100/250，连续两次真实选卡均不重置预算；最终夹具清盘仍只诊断。注入分数/锚点/最终清盘是测试条件，不是自然玩法样本。

BoardRunFlow 消费 recovery 步骤中的出生和结算结果，表现不重新扫描/出生。真实弹窗覆盖普通/快放/低特效/组合四模式，以及恢复演出中重试：旧局退休，新局恢复未解锁状态，旧回调不能修改新局。

# #134 · 关闭旧道具与重复补棋写入口

基于`develop/0.0.3`的`91154e2`。已复审并按作者授权合并#165：远端head为`0598374`，574项全量证据及SHA256核对通过，无评审反馈，合并提交`91154e2`。本片实现`0123c43`，独立分支`feature/134-retire-legacy-board-writes`，复杂迁移保留PR供作者review。

## 迁移结果与保留边界

| 原入口 | 处理 | 当前消费者/保留原因 |
| --- | --- | --- |
| Board开局/重试/F6/移除/ALIGN维护旧道具 | 删除注册、清理、注销和全局节点表重建 | 本局初始化与规则快照承担正式状态，表现只对齐实体/颜色/能力 |
| Board将视觉匹配再广播给MatchSystem | 退出转发 | BoardView仍发match_visualized表现事实；重复表现不重复规则/账本，旧match_made不再从正式局触发 |
| SpawnManager | 迁移4处测试调用后删除脚本、UID和Autoload | 核心和爆破测试设置本局安全步骤，调用现有Board.resume_run；不新增扣次/逐枚出生/await/终局循环 |
| ItemEffectSystem | 删除自动信号订阅、全局节点列表、节点查找及Autoload/脚本/UID | 没有保留自动触发兼容循环；时机枚举移至配置Resource，数值0～4保持 |
| ItemPlacer | 唯一测试消费者改为显式构造显示元数据，删除Autoload/脚本/UID | Board公开放置适配仍经BoardRules写入；不再隐式注册或执行旧效果 |
| ItemRegistry | 退出Autoload和自动注册，改为局部RefCounted配置工厂 | 核心显示元数据回归、局部A/B配置隔离测试；无场景查找或自动对局订阅。历史定义暂留，不进入正式技能池 |
| LevelUpSystem | 删除旧池注册/随机抽取/重置，保留只读进度查询 | 核心、奖励、阶段进度测试仍读兼容属性。查询消费者迁移完成后可另行退役Autoload，本片不要求删光单例 |
| 旧加分/染色/移除配置 | 显式局部调用 | 加分要求ledger；染色/移除要求run与coordinate。无GameManager、Board/UI或全局节点查找，不替代正式技能/命令管线 |
| MatchSystem | 删除无消费者的check_and_eliminate写方法，保留只读常量/查询及旧通知声明 | MIN_MATCH_COUNT广泛用于规则和夹具，查询由匹配测试使用；不扩清GameManager或其调试兼容入口 |

保留ItemData、历史配置模板和BoardView的只读素材映射，以支持显示兼容与局部配置测试；显示映射不执行效果、不代表第二份占格。不是把items目录翻译为SkillEffect，未迁移Resolver、导演或采集协议。

旧效果上下文不再接受隐式当前局：`EffectAddScore.apply({"ledger": local.state.ledger, "score": 100})`；染色/移除使用`{"run": local, "coordinate": Vector2i(2, 2)}`。缺少显式目标返回false，无全局fallback。局部配置必须由测试/调用者直接调用，不订阅真实对局。

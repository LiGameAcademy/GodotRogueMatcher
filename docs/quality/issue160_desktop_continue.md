# #160 桌面续局接管与退出切片

2026-10-30；基于 #220 的 `448cbc98211e7a737caa7d8cc0b8b6c453bc24a2`。本片不是 #160 或 O5 完成声明。既有规则重建与 Store 证据见 `issue160_safe_restore.md`；本片只改变应用接管与桌面调度，不改变计分、候选权重、阶段目标或随机协议。

## 最终行为

实际桌面入口开启单槽续局。输入安全点与冻结选卡点冻结本局数据，由一个 Thread 执行完整前缀验证、序列化及既有主备提交。加载使用当前应用配置构造的 manifest，拒绝原型/非正常初始化；完整验证成功后才一次接管 Board、HUD、预告与原候选。接管不再次 initialize、检查奖励、抽选、解锁或重播得分。旧 Run 退役、演出代次与缓冲输入失效；旧候选回调不能作用于新对象。

正常退出拒绝新输入并跳过无关演出，规则结清到输入点或原冻结候选后保存。不得自动替玩家选卡。失败提供重试、确认离开并保留旧档、取消；当前点与最近验证档完全相同可复用，不重复重建。真实终局尝试失效；待继续挑战的临时胜利不提前失效。重开先独立准备新局，再确认放弃并成功持久失效旧身份，最后挂载新局。

取消只撤销接管/退出意图，不取消正在执行的文件事务；worker 必须完成并 join 后才能再次使用 Store。取消期间的新安全点可以排队，不能替换旧 worker。新局、读取、终局失效与退出受同一串行所有权约束。忙碌时提供双语等待反馈。

场景线程只读取活跃局并冻结必要状态。CheckpointHistory 对新增记录深复制并递归设为只读，后续快照复用私有不可变记录；不冻结或修改公共 Recorder。worker 只接收冻结值与独占 Store；返回独立 Run 后先 join 再交给场景。恢复历史缓存也只在 worker 自有的新 Run 上建立。完整载荷、前缀、逐条序号、摘要、终点、身份及 manifest 校验仍保留。

旧采集段以 interrupted 关闭，不伪造自然终局/放弃，也不为恢复历史重发事件。本片明确暂停恢复后的采集，**尚未实现同 run 新 session/resume 段及高水位**。这避免虚增样本，但不是 SV10 通过。

## 真实 GPU 场景探针

RTX 2070、OpenGL 3.3/NVIDIA 610.88、Compatibility、1280×720。隔离 APPDATA，正常运行窗口内通过 viewport 输入命中实际继续和取消控件，截图是实际渲染结果；不是 Windows 物理鼠标黑盒，也不是作者试玩。工具自行正常退出，无强杀作者窗口。

正常局 GreedyBot seed 23 的 95 行动安全点：887 条记录、约 10.38 MB。取消后旧 Run 保留且 worker 仍占用；join 后再次继续，完整 RunSnapshot 相等、旧 Run 退役、输入开启。收到 `gpu_probe_save_and_quit` 正常退出信号；此处复用刚验证过的同一点，并非额外写入新代测试。相关菜单/加载/取消/恢复四张实际截图及 JSON 报告已归档。

第一次取消任务耗时 6.699 秒/391 帧，最大帧间隔 **207.039 ms**；测量包含同步 GPU 读回与 PNG 编码，freeze=0，因此不是保存冻结耗时，但缺少逐帧关联数据，不能证明尖峰由截图造成。第二次加载 6.717 秒/405 帧、最大 17.333 ms，中途没有截图。计时仅包围 worker 等待，不测接管后的整帧成本。旧窗口还记录 62.261/89.732 ms 间隔及当时最新的 14.200/26.171 ms 冻结；`last_job_metrics.freeze_usec`读取全局最新值，自动保存时可能属于较新的排队快照，**不作为刚完成 job 的冻结归因**。无逐帧因果记录，不能将整个间隔归因冻结、渲染或采样。这些事实不能改写成严格帧预算通过。

## 成本与边界

默认规则 API 2 秒接受门槛在正常局 50 行动已可超时。本桌面适配采用 **10 秒重建接受门槛**：完成 decode 后检查，不是可抢占超时，更不是端到端 10 秒保证。Thread 避免整段重建阻塞场景，但不保证所有主线程操作/驱动帧都无尖峰。取消按钮实际可达，取消不强停事务线程。

正常 GreedyBot classic/stage seed 7/23 实测自然终局分别 45/97/34/33 行动，不伪造 200 行动覆盖。长局缓存测量：95 行动 887 记录、10,379,690 字节、场景冻结 8.656 ms、worker 保存全程 8.792 秒、独立加载重建 5.672 秒；headless worker 等待最大 19.941 ms。所有实际安全点冻结最大 25.041 ms。终局在 97 行动/903 记录，95 并不等于最后可能保存点。无缓存版本该点冻结 273.668 ms，原记录与缓存后结果分别保留。

本次没有证明任意长局均可保存。15 MiB 内部载荷、16 MiB 容器及 4096 记录上限保持；超限明确失败且不覆盖旧档。载荷/前缀仍随局增长，保存与读取可能需数秒。性能数据按 headless 与真实 GPU 分列，不把机器操作速度当作真人体验。

# #130 普通出生和移动落定形变最小切片

## 范围与基线

从`70da633`的`develop/0.0.3`独立推进；不包含尚待作者review的#201，不自动合并任何PR。只改既有出生和落定的表现，不新增技能、规则或等待步骤，不将#130/O4整体标为完成。

静态场景新增`MotionVisuals`，既有NutVisual与PieceAbilityVisual同组，身体、五官、轮廓及箭头保持对齐；交互区域、选择光圈、根节点逻辑位置在外。只将本片的挤压拉伸写入局部缩放，避免与根节点的选择/移动/离场Tween争写同一scale。保留既有消除和特殊能力演出，未扩展它们的形变设计。

出生原duration内进行局部拉伸→接触挤压→回正，不在原出现演出后追加落定步骤；移动终点仍使用原60ms。低特效立即清局部形变，后续Tween方法不会重新写入变形，也不取消必要的出生/移动时钟。取消、重置、新移动、选择及离场清理局部姿态；取消出生恢复终态透明度，幽灵仍为0.5。

只读BoardJuiceConfig新增：birth_stretch=(0.88,1.12)、landing_squash=(1.10,0.94)、birth_landing_ratio=0.65、landing_seconds=0.06。以上为待作者试玩参数，不是正式体验或性能门槛。

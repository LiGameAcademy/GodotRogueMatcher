2026-10-21，基于 develop/0.0.3 的 3e4cc2b；#169（迁移阶段验收）与 #170（纯检测器）已按顺序复审通过并合并。本片使用已确认固定 L 模板及统一并集计分规则，不新增正式形状技能或候选配方。

## 配置与调用路径

BoardRules 构造可显式传入模板，构造时深拷贝；查询、读取配置副本、预算预览不能修改调用方 Resource 或另一局。默认构造仍只启用直线；没有全局开关，没有通过测试配置伪造正式解锁/取得历史。原型配置归本次 BoardRules，新的默认 BoardRules 回到直线；reset_counters 不是重新取得或解锁操作。

| 调用时点 | 统一入口与边界 |
| --- | --- |
| 合法移动提交后 | RunController.resolve_matches_at → BoardRules.find_matches_at：收齐直线和启用模板、传递合并后筛落点；无关的既存 L 不因这次移动自动消除 |
| 每枚出生后 | spawn_one → 同一落点检测；首枚匹配不终止剩余批次，颜色/顺序沿锁定预告，落点读取当前真实空间 |
| 同波批量改色后 | DyeRules.recolor 完成所有目标改色，再调用 BoardRules.find_matches；不会在三个子目标间提前消掉 L，丢失随后完成的直线并集 |
| 核心/扫线放置预算预检 | placement_preview 复制占格和同一模板配置；不再用直线专用预览漏算已启用的 L 匹配事件 |

直接移动匹配沿既有 direct_match 来源判免补。非空盘直接 L 匹配不消费预告或有限补棋次数；全清例外仍实际补棋并消费一次批次。出生、染色及后代匹配不会回写直接移动来源，不追授免补。既有奖励安全点、后代屏障和完整行动判关继续由 RunController/AbilityResolver 持有。

## 几何与记录

AbilityResolver 将 BoardMatchHit 深拷贝到 MatchResult，移除后仍保留形状/方向/实体/坐标；cause、root action、账本来源保持独立。含模板的事件增加 match_hits，混合直线与 L 可保留各自几何。

原型 Header config 增加可选 prototype_match_templates，只含形状身份及必要坐标；RuleReplay 在初始化前恢复相同配置，不从记录加载脚本或资源路径。最多 8 模板、每模板最多 4096 必需格、每轴偏移 −64～64，运行配置和记录解析共用限制。审查发现两端限制不一致后已统一，边界拒绝及 8 模板写录重放有回归。

保持 v41：默认直线配置和事件表示不增加字段，原 415 条记录精确回放通过；原型配置参与已有 config_hash，含模板事件的几何也逐项比较。此为构造时只读原型配置，不代表正式解锁状态、取得历史或任意安全存档协议已交付。

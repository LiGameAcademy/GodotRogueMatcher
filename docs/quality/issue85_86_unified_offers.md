# #85 / #86 统一抽选首片

本批延续 #161 的六条随机流及完整组事务。正式目录仍为 52 个技能，8 个形状解锁调试资源及 Composite 验收资源只补显式元数据，不进入正式池。没有新增技能 ID、Effect 或阶段目标表。

SkillOfferTraits 是技能 Resource 的只读抽选契约。mechanisms 描述所属机制，affinity 描述可关联路线，invests 描述成功取得后的历史投入；supplies、payoffs 分别声明持续供给与专属收益。needs 表达实际能力门槛。once_per_run、upgradeable、repeatable 必须三选一。is_persistent 仍描述持有实例，不用它推断效果持续时间或机制亲和。

SkillBuildSnapshot 每次从权威 RunState 投影，不新增可写状态。历史投入、持续供给、已建立收益分开保存。一次转化和有限效果不会冒充持续供给；普通场上引信只满足 live_fuse，不代表引信发动机；行列共用 line 路线。形状解锁记录 shape 投入，但不提高普通 T 技能关联权重。通用计分、消除数量不产生机制关联。

所有候选先经过同一 H 合法过滤，再进入单池。权重为 H × B(k) × Q × clamp(1 + a×related + d×fills_gap + s) × V。related 和 fills_gap 各为一次布尔加成，不按机制数或等级叠乘。fills_gap 仅补已投入路线尚缺的持续供给或首个专属收益。试运行 a=d=0.25，Q=V=1，s=0，稀有度五档 B 固定；阶梯曲线接口已有，但未编造随 k 变化的校准曲线。工具卡上限默认 1，可配置或关闭。

按技能 ID 的 ASCII 顺序逐槽加权无放回抽样，记录每槽候选权重、真实分母、采样值、选中项及配额排除。旧启动池、累计画像倍率、历史重复独立倍率和救援提前开放已删除。1/2/3 张合法非空组均有效；0 张不提交。抽选、顺序、目标三个临时流只有整组生成成功才回写，已有部分失效及完整失效修复语义保留。

记录协议为 run-commands-v45-unified-offers / offer-unified-trial-v1。冻结记录包含全部候选解释、构筑投影、参数与逐槽轨迹，分析器只消费事实，不重算游戏状态。旧记录不补造新协议字段；旧规则回放继续拒绝，历史证据不重写。

机会统计以分组 + parent_run_id（缺失时 run_id）+ reward_id 去重。同一奖励原组和替代组不重复计一次技能机会；失败选择不算取得。真人只有实际展示才算机会，机器人按生成组；合法池诊断独立为 legal_pool_rewards / observed_rewards，不能当作真人曝光。旧记录缺解释时资格率为 null。

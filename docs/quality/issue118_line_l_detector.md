# #118 第一片：直线与 L 模板统一检测

2026-10-21。前置迁移阶段验收见 PR #169；本片基于 develop/0.0.3 的 ea111675，代码提交 efe7e64。#136 阶段验收通过不代表 #135/#136 整版关闭。

## 范围与规则

按 GDC「棋盘与生成」「计分与数值验证」实现无 UI 检测器。BoardRules 原有四方向直线算法迁入 BoardMatchDetector，正式入口仍不传异形模板。L 配置为五格 `X../X../XXX`，只通过显式模板参数参与原型计算；没有新增正式技能、运行时解锁开关或候选池。

模板旋转、镜像后归一化并去重，不缩放、不跨边界；额外同色格不自动纳入模板。先收集全部命中，再按共享实体传递合并，最后筛选落点。并集实体只结算一次。BoardMatchHit 保存形状、几何锚点、方向、实体和坐标副本；几何锚点不替代行动来源，后者仍归调用方。删除棋子后保留命中几何，结果不引用可变棋盘对象。

配置缺失、匿名/保留形状名、空模板和重复必要格明确拒绝。代码审查发现重复格可虚增计数，已先用失败测试复现，再修复并复审通过。

## 验证与限制

新增 10 项规则回归：正式入口直线限定；L 旋转/镜像和重复模板去重；缺格、异色、越界；额外同色不延伸；直线与 L 重叠并集 7 格计 104 分；传递重叠与独立组；查询不改状态、输出资源隔离；独立 L 两组计 110 分；整批匹配先移除再派发爆破；错误模板诊断且不改状态。

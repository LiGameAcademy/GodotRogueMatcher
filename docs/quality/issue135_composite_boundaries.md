# #135首片 · 正式发牌与组合目标生命周期

PR #167基线36ffe5b；初版e8bf0b3的v36证据保留在docs/evidence/issue135。作者review指出正式发牌仍预抽动态叶，这个缺口成立：初版只证明runner内部不批量刷新，不能据此宣称整个生命周期每叶仅抽一次。本次实现8c7d5e3，规则v38，以下结论替代初版的相应表述。

## 状态与修改入口

TargetPolicy写在只读Effect配置；SkillTarget.deferred和固定实体快照归本局RewardState。copy保持树结构/延迟契约且不共享可变数组。查看卡面只显示“目标在执行时选择”，不伪造颜色/数量，不抽样。RunSnapshot递归记录每叶的固定值或延迟契约，规则版本v38拒绝旧v36。

AbilityEffectRunner只读预检所有叶的已知前置，不调用动态freeze、不执行预演。已知坏颜色/预算不足在首叶前拒绝且无规则副作用；尚未发生的前叶影响不靠预演预测。执行时匹配即时入账/移除，触发后代等根组合结束。固定目标允许失效时由具体叶build_surviving过滤并校验，不把任意请求error清空；不可缩减的效果沿原诊断拒绝。空附引信跳过不安装引信路线。

SkillApplyResult区分rejected/applied/error；target_changes保留固定部分/空目标的原因、原集合与剩余集合。提交后故障保留已提交收益、ERROR锁定，原奖励不成功消费；等待的激活取消并记录interrupted/composite_aborted，不伪称爆破成功或合法空结果。RuleResult记录分类与目标变化。

具体职责仍为runner→DyeRules/RunController→AbilityResolver→BoardRules/ScoreLedger；不查UI、不依赖动画、不新增通用调度框架。颜色权重的数值刷新保留已冻结颜色，不重新抽身份。

## 新增回归与实际覆盖

新test_composite_offer_lifecycle六项：

1. 正式生成候选中的嵌套染色均0次freeze，应用后各1次；候选重校验不抽样，重复提交不抽样。
2. 动态比例清理/疏整/行清理/附引信在清色后的盘面选择，结果与独立新盘面的一次freeze相同，RNG游标相同。
3. 预览、copy、递归记录和缺失必要颜色的前置拒绝，不执行动态叶且不改本局快照。
4. B03固定失效A合法空附引信，F仅外层结束执行；B04严格失效在已提交50分后ERROR、后代明确中断且不泄漏。
5. 固定{A,Q}只保留Q，第三叶倍率完成，不追溯50分；已知坏颜色在首叶前拒绝。
6. SKIP_INVALID不能抹掉预算不足的前置拒绝。

这些自定义组合走真实候选生成、freeze_target与SkillRules.apply，不冒充正式Catalog新卡或从初始局面磁盘恢复。既有Catalog的ChooseSkillCommand/场景/机器人/回放由完整回归与新局记录验证。

旧B01/B02测试保留叶间检查点，预检允许只读检查固定叶，执行检查点单独计数。后叶异常夹具改为前置合法、前叶提交后才故障，避免把已知坏请求误称执行中异常。旧定向场景手工指定行实体时显式声明FIXED；合法动态空染色需要allow_empty_targets声明。

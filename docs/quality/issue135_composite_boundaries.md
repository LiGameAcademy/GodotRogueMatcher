# #135首片 · Composite顺序与目标刷新

基线`36ffe5b`，#166已由作者review后合并；本片实现`e8bf0b3`，规则版本`run-commands-v36-composite-boundaries`。按O5顺序从#134进入#135，不重复实现O1/O2，不关闭#135或宣称里程碑质量收口。

## 目标与实际改动

核查现有扩展入口时复现两个缺口：DYE叶调用完整resolve，五连后的F爆破提前移除第二叶需要的Q；执行器刷新整棵子树，再刷新内层后叶，造成重复抽样。此外ChoiceEffect默认refresh会重新freeze，固定材料目标可能被暗换。

本片依已确认Composite方案B完成局部修正：匹配立即计分和移除，爆破、匹配附引信等后代留在本局Resolver，最外层结束才处理；嵌套返回不flush。附引信资格在匹配触发时判定，后叶新装能力不追授旧匹配。发生后叶异常时保留已提交匹配，清空等待队列，ERROR锁定且不成功消费原奖励。运行时规则错误从叶/flush返回，不能被当成普通成功。

固定目标默认保留；TransformMaterialEffect默认保留来源，仅显式配置reselect_after_previous=true时在后叶重选。DyeMaterialEffect明确重选动态目标，RefillCountEffect只重算受前叶影响的数值，ColorWeightEffect继续保持冻结颜色。进入子树不再提前抽整个子树；每个动态叶到达时抽一次。没有新建通用调度框架或加入正式技能。

## 职责映射与关闭旧入口

- AbilityEffectRunner把hold语义向下传给染色与新生匹配；只有最外层提交结束时flush。旧的子树批量刷新调用已退出执行路径。
- AbilityResolver仍唯一提交匹配/移除/账本与后代，新增等待事实和异常清理；RunController只转交显式hold参数。
- ChoiceEffect默认refresh不抽样；动态染色与数值更新由具体叶明确覆盖。CompositeEffect.refresh_after_previous仍被test_composite_preview直接验证冻结颜色，未作为正式执行入口或UI预览服务调用。
- SkillRules继续拥有奖励消费与ERROR状态；不额外造事务回滚或通用原子效果。

## 规则证据与覆盖边界

新增test_composite_boundaries五项：

1. B01：改A红后五连50分已兑现，Q/R仍存活、F待执行；固定Q得到引信后，F→Q→R按来源顺序离场，固定目标不抽随机。
2. B02：外层[内层[改A红]；给Q附引信]与B01同样中间检查点、结果和随机游标；内层不释放后代。
3. 动态嵌套：第二子树中两个显式动态叶各抽一次；验证调用次数及实际随机游标，不只对比终盘。
4. 后叶失败：匹配50分保留、原奖励不消费、ERROR锁定、待执行匹配/爆破清空，后续flush不漏执行。
5. 附引信资格：触发时未拥有则后叶取得不能追授，触发时拥有则后叶变更不撤销已排队资格；目标在执行时仍按存活盘面选择。

B01/B02使用规则层固定测试组合直接调用runner，未伪称已通过自定义卡的正式选卡/磁盘恢复。实际Catalog的命令与回放沿现有回归验证。第一版RED访问不存在的第4个结果曾触发测试下标错误；加长度保护后语义RED仍3项失败（18/30断言通过），修复后首组20项通过。补异常测试时曾给ChoiceEffect字段传Composite导致脚本被GUT跳过，日志中虽显示剩余用例通过，但不作为成功证据；改用真实AbilityDefinition/SkillLevelDefinition配置后重新验证完整5脚本。初轮定向22/22测试、122断言通过，0.094秒、退出0。首次全量发现旧双批转化夹具依赖隐式重选（585/586通过、3断言失败）；为该测试的独占第二叶显式配置重选，并新增默认固定来源失效且不耗随机的回归。最终定向含特殊转化，共6脚本31/31测试、544断言，0.783秒。

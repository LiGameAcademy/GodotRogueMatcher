# #130 主按钮和设置面板 UI 动画最小切片

## 范围与行为

基线：`70da6337aef9f0e32c5fbe78c981dd2c0fca3113`，目标分支 `develop/0.0.3`。
仅处理现有 UI 操作反馈，未新增玩法需求，也不关闭 #130/O4。

- 静态 `FeedbackButton` 场景复用于 HUD 设置/暂停、主菜单开始（继续）/设置、设置面板关闭/返回菜单/略过，共七处。
- 仅 Tween 自身色调；不缩放按钮或移动命中区域，不替代原生按键派发、Theme 焦点/禁用样式。
- 设置打开立即取得暂停和焦点，面板淡入。关闭立即隐藏输入面板、恢复原暂停状态和焦点；只允许无输入的背景遮罩短暂淡出。
- 重开/低特效/退役取消旧 Tween，关闭回调校验代次；动画不参与规则、计分、抽选或必要演出屏障。
- `UiMotionConfig` 只读共享：按钮90ms、面板淡入140ms、遮罩淡出90ms，悬停1.06、按下0.90。属于本片待作者试玩调参，不能当作正式体验门槛。
- 快速播放与低特效独立；低特效立即切换按钮及面板视觉状态。保留原有节点名和公开 UI 引用，新增内部引用使用私有命名。

# 技能卡交互与复用（#8）

## 玩家操作

点击卡片只预选、显示选中边框，不取得技能；在三选一面板底部按统一确认按钮才提交。选色卡先选卡、选色，再用同一个底部按钮确认。查看棋盘/卡池、暂停、换卡和返回不改变候选或奖励。提交失败保留候选；重复确认不重复提交。

## 组件边界

- ui/skill_card.tscn + 同名脚本：选卡与卡池共用竖卡，256×352基础比例；卡池使用只读配置，继续GridContainer筛选排序。已拥有技能保留只读横卡。
- PopupSkillChoice：只拥有预选状态和统一确认入口，发出选择信号，由LevelUpSystem执行原选择命令。
- ColorTargetPicker：发出color_chosen更新确认按钮状态；嵌入三选一时隐藏其旧确认按钮，保留独立场景自身能力。
- 只有成功命令回执调用accept_selection(true)，才发出card_acquired；关闭/重试/拒绝不伪造成功。
- Game协调来源矩形与HUD目标，调用独立ui/card_transfer/card_transfer.tscn。持久/消耗卡飞向构筑区，即时卡飞向使用记录入口；表现组件不查找外部节点或修改规则。

## 动效与生命周期

展示候选时卡背→正面翻卡；成功取得后缩小飞入目标区域。Tween仅控制表现，没有动画结束回调决定计分、奖励或下阶段。低特效跳过两种动画；切换低特效与重试取消旧飞行。飞行卡及其子文字忽略鼠标，避免覆盖按钮造成新误触。每张卡的StyleBox独占，卡池仍只读、不冻结或重抽目标。

Godot 4.7.2。第一轮13个界面/主场景脚本98项测试通过；最终7个相关脚本48项测试通过（2082断言），包含新增6项防误触/动画/取消行为案例、教学、原奖励演出、快放/暂停/跳过、卡面布局和命令回放。额外完整44卡与扫线修复由PR #90的31项规则测试覆盖。第一轮复验发现的扫线空执行已在独立PR修复，不隐去失败历史。

真实Compatibility渲染（英文小窗口有效视口1024×576，按项目比例缩放）检查了中文选卡、预选、卡池、飞行过程和英文小窗口；两种语言的1280×720/1024×640布局由原卡面测试遍历44卡。保留截图与日志在隔离开发工程的.godot/issue8-*。没有导出Web，不宣称整库测试或作者视觉验收已完成。未修改技能数值、权重或随机算法；随机优化归0.0.3。

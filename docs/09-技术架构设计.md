## 三、核心系统架构 (Core Systems Architecture)

### 1. GameManager (游戏管理器)

#### 1.1 职责
- 全局游戏状态管理
- 回合管理
- 分数计算
- 安全等级管理
- 关卡管理

#### 1.2 接口
```gdscript
# GameManager.gd (Autoload)
extends Node

signal turn_started()
signal turn_ended()
signal level_completed(level: int)
signal game_overed(reason: String)

var current_level: int = 1
var current_score: int = 0
var target_score: int = 1000
var coins: int = 0
var turn_count: int = 0
var security_level: int = 1

func start_turn():
    turn_started.emit()
    # 执行回合开始逻辑

func end_turn():
    turn_ended.emit()
    # 执行回合结束逻辑
    check_level_complete()
    check_game_over()
```

### 2. GridManager (网格管理器)

#### 2.1 职责
- 管理 9x9 网格数据
- 处理坐标转换
- 管理实体位置
- 处理碰撞检测

#### 2.2 接口
```gdscript
# GridManager.gd
extends Node

var grid_data: Dictionary = {}  # {Vector2i: EntityData}
var a_star: AStarGrid2D

func initialize_grid(rows: int, cols: int):
    a_star = AStarGrid2D.new()
    a_star.region.size = Vector2i(rows, cols)
    a_star.diagonal_mode = AStarGrid2D.DIAGONAL_MODE_NEVER
    a_star.update()

func get_path(from: Vector2i, to: Vector2i) -> Array:
    return a_star.get_point_path(from, to)

func is_available(pos: Vector2i) -> bool:
    return not grid_data.has(pos) or not grid_data[pos].is_blocking

func place_entity(entity: Node, pos: Vector2i) -> bool:
    if not is_available(pos):
        return false
    grid_data[pos] = EntityData.new(entity)
    a_star.set_point_solid(pos, entity.is_blocking)
    return true
```

### 3. EntitySpawner (实体生成器)

#### 3.1 职责
- 生成球
- 生成威胁（死像素、粘滞扇区）
- 生成交互实体（宝箱、黑市）
- 管理生成概率和限制

#### 3.2 接口
```gdscript
# EntitySpawner.gd
extends Node

func spawn_balls(count: int):
    for i in range(count):
        var pos = get_random_empty_cell()
        if pos != Vector2i(-1, -1):
            spawn_ball_at(pos)

func spawn_threats(security_level: int):
    if randf() < get_dead_pixel_chance(security_level):
        spawn_dead_pixel()
    # ...
```

## 四、信号系统 (Signal System)

### 1. SignalBus (信号总线)

全局信号总线，解耦系统间通信：

```gdscript
# SignalBus.gd (Autoload)
extends Node

# 消除相关
signal match_made(score: int, center_pos: Vector2i, matched_pieces: Array)
signal chain_reaction(chain_count: int)

# 回合相关
signal turn_started()
signal turn_ended()
signal round_ended()

# 经济相关
signal coin_earned(amount: int)
signal coin_spent(amount: int, item: ItemData)

# 实体相关
signal item_placed(item: ItemData, pos: Vector2i)
signal item_removed(item: ItemData, pos: Vector2i)
signal building_activated(building: Node, effect: Dictionary)

# 游戏状态
signal level_completed(level: int, score: int)
signal game_overed(reason: String)
signal security_level_increased(level: int)

# 威胁相关
signal threat_spawned(threat_type: String, pos: Vector2i)
signal threat_removed(threat_type: String, pos: Vector2i)
```

### 2. 信号使用示例

```gdscript
# 在消除时发出信号
SignalBus.match_made.emit(score, center_pos, matched_pieces)

# 在其他地方监听
SignalBus.match_made.connect(_on_match_made)

func _on_match_made(score: int, center_pos: Vector2i, matched_pieces: Array):
    # 处理消除逻辑
    pass
```

## 七、性能优化 (Performance Optimization)

### 1. 对象池 (Object Pooling)

```gdscript
# ObjectPool.gd
extends Node

var ball_pool: Array[ChessPiece] = []
var effect_pool: Array[Node] = []

func get_ball() -> ChessPiece:
    if ball_pool.is_empty():
        return create_new_ball()
    return ball_pool.pop_back()

func return_ball(ball: ChessPiece):
    ball.reset()
    ball_pool.append(ball)
```

### 2. 批量处理

```gdscript
# 批量处理消除检测
func check_all_matches() -> Array[MatchData]:
    var matches = []
    # 批量检测，避免每帧检测
    for pos in get_all_positions():
        var match = check_match_at(pos)
        if match:
            matches.append(match)
    return matches
```

### 3. 延迟更新

```gdscript
# 非关键更新延迟到下一帧
func update_non_critical():
    call_deferred("_update_ui")
    call_deferred("_update_effects")
```

## 八、代码组织原则 (Code Organization Principles)

### 1. 单一职责原则
- 每个类只负责一个功能
- 避免类过于庞大

### 2. 组合优于继承
- 使用组合实现功能扩展
- 避免深度继承层次

### 3. 信号解耦
- 使用信号进行系统间通信
- 避免直接引用

### 4. 资源驱动
- 使用 Resource 存储数据
- 便于扩展和修改

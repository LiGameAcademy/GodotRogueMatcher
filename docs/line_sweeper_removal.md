# 行列清除手：固有离场扫线（#74 首片）

行清除手、列清除手登场时即有离场能力。五连或爆炸移除棋子后，以离场时坐标扫其所在行或列；普通材料（含引信）被清除，其他特殊伙伴、爆壳手、其他扫线手保留。不会额外消耗行动或补棋。扫到引信继续走爆破队列。

规则源：GDC/acceptance/0.0.2-O2行列清除第二BD设想.md §3.2–3.4。

## 结算与状态

- `LineSweepEffect` 只查目标；`AbilityResolver` 统一提交占格、账本与离场事件。
- 定义 Resource 只读；每枚棋子的触发次数由 `LineClearState.instances` 独立持有。自然补给和技能登场均安装。
- 与爆破共用确定性离场队列：按代数、来源 ID 排序，目标在执行时重新查询。同轴重叠只结算存活目标一次；空轴也消费本次离场触发，不给分。
- 直接扫线使用现有常规账本：基础分 `n*(n+5)`（沿用现行 n>=5 条件）、全局分数倍率及消除额外得分；引信/染色标记收益另加。不算同色五连，因此不触发精准五连、长线、五连种引信、五连染色；也不计爆炸次数。少于五枚的基础分目前为零；此片不更改原始计分公式。
- 引信爆炸独立入账；爆破余震在包含扫线的整条队列清空后正常收束。
- 组合技能中的离场扫线与爆破一起延迟至组合叶子执行完成，使用冻结来源与执行时的存活目标。
- 扫线实例纳入事件预算与快照；技能登场 preflight 也计算新实例。版本为 `run-commands-v26-line-removal-sweep`，旧记录保留，但不声称能在新规则下继续回放。
- RuleResult 记录 `line_clear`、`line_axis`、来源、代数、直接得分和离场 activation 的 parent/source ability；表现只消费结果，沿用消除动画与漂字。

## 手动验收

1. 获得「列清除手登场」，移动它组成横向或斜向五连。棋子消除后，所在列的普通棋子应清除，其他列不受直接扫线影响。
2. 行清除手对应检查所在行。
3. 同轴引信应继续爆炸；爆壳手和另一枚扫线手不会被直接扫线删除（后续引信爆炸仍按爆破规则命中）。
4. 顶部总分 tooltip 应区分扫线与爆炸；不足五枚的扫线沿用零基础分。

主动双击、空轴确认，以及 #75 跨度/十字/得分升级尚未包含；#74 保持开放。

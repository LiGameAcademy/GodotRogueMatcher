# 比例清理试调（#49）

2026-10-10，接续作者已试玩通过并合并的压力救场首片 PR #48。

## 本片规则

新增“随机疏林”：对普通棋子集合随机无放回清理25%，数量向下取整，包含引信、排除特殊伙伴。少于4枚普通棋时不进入候选，不暗改为至少清1枚。候选与实际目标冻结，查看技能池或返回不重抽；提交前检查数量、目标存活与重复ID。

直接清理不计分，触发的引信后代按原计分账本结算，所得分统一推进累计目标；选卡不耗有效行动、不额外普通补棋，达标检验仍要求新有效行动。特殊伙伴不被直接抽选，但后代爆炸仍按原目标规则处理。

比例25%、基础权重5、稀有度“稀有”、第3次奖励起均为试调配置，不是已验证的平衡结论。该卡沿用高压提前资格、压力权重与每组最多一张即时工具。两种模式都可出现本卡；经典模式仍不受压力权重影响。运行池39项，技能池使用已有卡牌网格与筛选排序。

比例配置在 `gameplay/progression/content/instant_percent_clear.tres`。纯规则由 PercentClearEffect 负责，调用现有 CLEAR 请求入口；UI只显示冻结的实际清理数量。运行规则版本为 `run-commands-v11-percent-clear`，候选版本同时更新，配置及比例进入记录哈希；旧记录保留，不宣称当前精确回放兼容旧版本。

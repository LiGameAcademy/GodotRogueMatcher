# 存档系统设计 (Save System Design)

---

## 一、存档需求 (Save Requirements)

### 1. 需要保存的数据
- **游戏进度：** 当前关卡、最高关卡
- **游戏状态：** 当前局内的棋盘状态、建筑布局、金币数
- **统计数据：** 总游戏时长、最高分数、最高连击等
- **设置数据：** 音量、语言、难度等
- **成就数据：** 已解锁的成就

### 2. 存档时机
- **自动存档：** 
  - 每回合结束后
  - 关卡完成时
  - 游戏退出时
- **手动存档：** 
  - 玩家主动保存（可选功能）
- **检查点存档：** 
  - 关卡开始时
  - 重要事件发生时

## 三、防作弊方案 (Anti-Cheat System)

### 1. 数据校验 (Data Validation)

#### 1.1 校验和 (Checksum)
- **算法：** SHA-256 或 MD5
- **计算内容：** 关键游戏数据（分数、关卡、金币等）
- **存储位置：** 存档文件的 `checksum` 字段
- **验证时机：** 加载存档时

```gdscript
# 计算校验和
func calculate_checksum(data: Dictionary) -> String:
    var json_string = JSON.stringify(data)
    return json_string.sha256_text()

# 验证校验和
func verify_checksum(data: Dictionary, checksum: String) -> bool:
    return calculate_checksum(data) == checksum
```

#### 1.2 数据范围验证
- **分数验证：** 检查分数是否在合理范围内
- **关卡验证：** 检查关卡数是否 <= 最大关卡数
- **金币验证：** 检查金币数是否合理（不能为负数，不能过大）
- **建筑验证：** 检查建筑数量是否合理

```gdscript
func validate_game_data(data: Dictionary) -> bool:
    # 验证分数
    if data.score < 0 or data.score > MAX_REASONABLE_SCORE:
        return false
    
    # 验证关卡
    if data.level < 1 or data.level > MAX_LEVEL:
        return false
    
    # 验证金币
    if data.coins < 0 or data.coins > MAX_REASONABLE_COINS:
        return false
    
    return true
```

#### 2.2 存档文件混淆
- **方法：** Base64 编码 + 简单混淆
- **目的：** 防止直接修改 JSON 文件
- **注意：** 不是真正的安全，只是增加修改难度

### 3. 逻辑验证 (Logic Validation)

#### 3.1 游戏状态一致性
- **建筑验证：** 检查建筑位置是否合法
- **球验证：** 检查球的数量和位置是否合理
- **金币验证：** 检查金币获取是否合理（根据分数计算）

```gdscript
func validate_game_state(state: Dictionary) -> bool:
    # 验证建筑位置
    for building in state.buildings:
        if not is_valid_position(building.position):
            return false
        if not is_available_cell(building.position):
            return false
    
    # 验证球的数量
    var total_cells = state.grid_size.x * state.grid_size.y
    var occupied = state.buildings.size() + state.balls.size()
    if occupied > total_cells:
        return false
    
    # 验证金币合理性
    var expected_coins = calculate_expected_coins(state.score)
    if abs(state.coins - expected_coins) > TOLERANCE:
        return false  # 金币与分数不匹配，可能作弊
    
    return true
```

#### 3.2 时间戳验证
- **保存时间：** 记录存档时间
- **加载时间：** 检查存档时间是否合理
- **游戏时长：** 验证游戏时长是否合理

```gdscript
func validate_timestamps(save_time: String, playtime: int) -> bool:
    var save_datetime = Time.get_datetime_dict_from_system()
    var save_timestamp = Time.get_unix_time_from_system()
    
    # 检查存档时间不能是未来
    if save_timestamp > Time.get_unix_time_from_system():
        return false
    
    # 检查游戏时长是否合理
    if playtime < 0 or playtime > MAX_REASONABLE_PLAYTIME:
        return false
    
    return true
```

## 四、存档实现 (Save Implementation)

### 1. 存档管理器 (SaveManager)

```gdscript
# SaveManager.gd (Autoload)
extends Node

const SAVE_DIR = "user://saves/"
const SAVE_FILE = "save_slot_1.json"
const SECRET_KEY = "your_secret_key_here"  # 应该混淆或从服务器获取

func save_game(game_data: Dictionary) -> bool:
    # 1. 准备存档数据
    var save_data = {
        "version": "1.0",
        "save_time": Time.get_datetime_string_from_system(),
        "game_data": game_data,
        "settings": get_settings(),
        "achievements": get_achievements()
    }
    
    # 2. 计算校验和
    var checksum = calculate_checksum(save_data.game_data)
    save_data["checksum"] = checksum
    
    # 3. 加密敏感数据（可选）
    # save_data["game_data"] = encrypt_data(save_data["game_data"], SECRET_KEY)
    
    # 4. 保存到文件
    var file_path = SAVE_DIR + SAVE_FILE
    var file = FileAccess.open(file_path, FileAccess.WRITE)
    if file == null:
        return false
    
    file.store_string(JSON.stringify(save_data))
    file.close()
    
    return true

func load_game() -> Dictionary:
    var file_path = SAVE_DIR + SAVE_FILE
    var file = FileAccess.open(file_path, FileAccess.READ)
    if file == null:
        return {}
    
    var json_string = file.get_as_text()
    file.close()
    
    var json = JSON.new()
    var parse_result = json.parse(json_string)
    if parse_result != OK:
        return {}
    
    var save_data = json.data
    
    # 验证校验和
    if not verify_checksum(save_data.game_data, save_data.checksum):
        print("警告：存档数据校验失败，可能被修改")
        # 可以选择拒绝加载或标记为可疑
    
    # 验证数据范围
    if not validate_game_data(save_data.game_data):
        print("错误：存档数据验证失败")
        return {}
    
    return save_data

func delete_save() -> bool:
    var file_path = SAVE_DIR + SAVE_FILE
    if FileAccess.file_exists(file_path):
        DirAccess.remove_absolute(file_path)
        return true
    return false
```

## 七、存档安全建议 (Security Recommendations)

### 1. 开发阶段
- **调试模式：** 允许直接修改存档（开发用）
- **发布版本：** 启用所有防作弊检查

### 2. 发布后
- **定期更新密钥：** 定期更换加密密钥
- **监控异常数据：** 记录可疑存档数据
- **玩家反馈：** 收集存档损坏报告

### 3. 注意事项
- **防作弊不是万能的：** 本地存档总是可以被修改
- **平衡体验：** 不要因为防作弊影响正常玩家体验
- **错误处理：** 存档损坏时提供恢复选项

# UI/UX 设计文档 (UI/UX Design Document)

---

## 一、设计原则 (Design Principles)

### 1. 核心原则
- **清晰性：** 信息清晰易懂
- **一致性：** 界面风格统一
- **反馈性：** 操作有明确反馈
- **效率性：** 减少不必要的操作步骤

### 2. 视觉风格
- **主题：** 暗黑赛博 / CRT 终端风格
- **配色：** 深色背景 + 霓虹色高亮
- **字体：** 等宽字体（Monospace）
- **图标：** 像素风格 / SVG 图标

---

## 二、界面结构 (Interface Structure)

### 1. 主界面布局

#### 1.1 屏幕分区
```
┌─────────────────────────────────────┐
│  顶部栏 (Top Bar)                    │
│  [安全等级] [分数] [金币] [回合]      │
├─────────────────────────────────────┤
│                                     │
│        游戏区域 (Game Area)          │
│         9x9 棋盘                     │
│                                     │
├─────────────────────────────────────┤
│  商店栏 (Shop Bar)                   │
│  [商品1] [商品2] [商品3] [刷新]      │
└─────────────────────────────────────┘
```

#### 1.2 各区域说明
- **顶部栏：** 显示关键信息（安全等级、分数、金币、回合数）
- **游戏区域：** 9x9 棋盘，占据屏幕中央
- **商店栏：** 底部常驻，显示可购买物品

---

## 三、界面组件 (UI Components)

### 1. 顶部栏 (Top Bar)

#### 1.1 安全等级显示
- **位置：** 左上角
- **显示内容：** 
  - 文字：`SECURITY LEVEL: 3` 或 `TRACE: [||||||....]`
  - 进度条：显示当前回合 / 15
- **颜色：** 
  - Lv.1-2：绿色
  - Lv.3：黄色
  - Lv.4+：红色
- **交互：** 悬停显示详细信息

#### 1.2 分数显示
- **位置：** 顶部中央
- **显示内容：** `SCORE: 15,000 / 20,000`
- **进度条：** 显示分数进度
- **动画：** 分数变化时数字跳动

#### 1.3 金币显示
- **位置：** 右上角
- **显示内容：** `💰 500` 或 `$ 500`
- **动画：** 金币变化时数字跳动，飞入/飞出动画

#### 1.4 回合显示
- **位置：** 顶部右侧
- **显示内容：** `TURN: 15`
- **用途：** 显示当前回合数

### 2. 游戏区域 (Game Area)

#### 2.1 棋盘显示
- **背景：** 深灰色网格，带有扫描线效果
- **网格线：** 浅灰色，1 像素
- **单元格：** 64x64 像素
- **高亮：** 选中时高亮显示

#### 2.2 路径显示
- **显示时机：** 选中棋子后，鼠标悬停在空位时
- **显示方式：** 高亮路径上的所有格子
- **颜色：** 蓝色/青色
- **动画：** 路径闪烁效果

#### 2.3 危险提示
- **触发条件：** 剩余空位 < 10
- **显示方式：** 屏幕边缘闪烁红色
- **强度：** 随剩余空位减少而增强

### 3. 商店栏 (Shop Bar)

#### 3.1 商品卡片
- **尺寸：** 80x80 像素
- **内容：** 
  - 图标（64x64）
  - 名称
  - 价格
- **状态：** 
  - 正常：正常显示
  - 金币不足：灰色显示
  - 悬停：高亮显示

#### 3.2 拖拽反馈
- **拖拽时：** 显示半透明商品预览，跟随鼠标
- **有效位置：** 高亮绿色
- **无效位置：** 高亮红色
- **释放时：** 播放购买音效

#### 3.3 刷新按钮
- **位置：** 商店栏右侧
- **显示：** `刷新 ($5)`
- **状态：** 
  - 正常：可点击
  - 金币不足：灰色，不可点击

## 四、弹窗界面 (Popup Interfaces)

### 1. 游戏结束弹窗 (Game Over Popup)

#### 1.1 内容
- **标题：** "GAME OVER" 或 "内存溢出"
- **统计信息：** 
  - 最高连击数
  - 使用建筑数
  - 存活回合数
  - 获得总分数
  - 达到的关卡数
- **按钮：** 
  - "重试" (Retry)
  - "退出" (Quit)

#### 1.2 样式
- **背景：** 半透明黑色背景
- **边框：** 霓虹色边框
- **动画：** 淡入动画

### 2. 关卡完成弹窗 (Level Complete Popup)

#### 2.1 内容
- **标题：** "LEVEL COMPLETE" 或 "防火墙破解成功"
- **奖励信息：** 
  - 获得金币数
  - 剩余空位数
- **按钮：** 
  - "下一关" (Next Level)
  - "返回菜单" (Back to Menu)

### 3. 设置弹窗 (Settings Popup)

#### 3.1 内容
- **音量设置：** 
  - 主音量滑块
  - 音效音量滑块
  - 音乐音量滑块
- **语言设置：** 
  - 中文 / English 切换
- **难度设置：** 
  - 简单 / 普通 / 困难
- **按钮：** 
  - "应用" (Apply)
  - "取消" (Cancel)

### 4. 排行榜弹窗 (Ranking Popup)

#### 4.1 内容
- **排行榜列表：** 
  - 排名
  - 玩家名称
  - 最高分数
  - 达到关卡
- **按钮：** 
  - "关闭" (Close)

## 五、交互设计 (Interaction Design)

### 1. PC 端交互

#### 1.1 鼠标操作
- **左键点击：** 选中/移动/放置
- **右键点击：** 取消选择（可选）
- **鼠标悬停：** 显示详细信息
- **鼠标拖拽：** 从商店拖拽物品到棋盘

#### 1.2 键盘快捷键（可选）
- **ESC：** 打开菜单/关闭弹窗
- **R：** 快速重试
- **空格：** 暂停/继续

### 2. 移动端交互（未来）

#### 2.1 触控操作
- **点击：** 选中/移动/放置
- **长按：** 显示详细信息
- **拖拽：** 从商店拖拽物品到棋盘
- **双指缩放：** 缩放棋盘视图（可选）

#### 2.2 适配考虑
- **按钮大小：** 至少 44x44 像素（触控友好）
- **间距：** 足够的间距避免误触
- **响应区域：** 扩大可点击区域

## 六、反馈系统 (Feedback System)

### 1. 视觉反馈

#### 1.1 操作反馈
- **点击反馈：** 按钮按下效果
- **悬停反馈：** 高亮显示
- **拖拽反馈：** 半透明预览

#### 1.2 游戏反馈
- **得分提示：** 大号数字从消除中心飞出
- **连击提示：** 屏幕顶部显示连击数
- **金币提示：** 金币图标从消除位置飞向金币栏
- **危险提示：** 屏幕边缘闪烁红色

### 2. 音效反馈

#### 2.1 UI 音效
- **点击：** 清脆的机械键盘声
- **购买：** 收银机声
- **错误：** 低沉的错误音

#### 2.2 游戏音效
- **消除：** 合成器电子音
- **连击：** 音调递增（Do, Re, Mi...）
- **警报：** 低沉的蜂鸣声

### 3. 触觉反馈（移动端）
- **点击：** 轻微震动
- **消除：** 中等震动
- **连击：** 强烈震动

---

## 七、新手引导 (Tutorial System)

### 1. 引导流程

#### 1.1 基础移动引导
- **步骤1：** 提示点击球
- **步骤2：** 提示点击空位
- **步骤3：** 演示路径显示和移动

#### 1.2 消除机制引导
- **步骤1：** 提示形成 5 连
- **步骤2：** 演示消除效果
- **步骤3：** 说明得分计算

#### 1.3 商店系统引导
- **步骤1：** 提示查看商店
- **步骤2：** 演示拖拽购买
- **步骤3：** 说明金币获取

#### 1.4 建筑放置引导
- **步骤1：** 提示放置第一个建筑
- **步骤2：** 说明建筑效果
- **步骤3：** 演示建筑回收

### 2. 引导样式
- **高亮：** 高亮相关元素
- **箭头：** 指向操作目标
- **文字提示：** 简洁明了的说明文字
- **跳过选项：** 允许跳过引导

## 八、响应式设计 (Responsive Design)

### 1. 屏幕适配

#### 1.1 PC 端
- **最小分辨率：** 1280x720
- **推荐分辨率：** 1920x1080
- **适配方式：** 固定尺寸，居中显示

#### 1.2 移动端（未来）
- **最小分辨率：** 720x1280（竖屏）
- **推荐分辨率：** 1080x1920（竖屏）
- **适配方式：** 缩放适配，保持比例

### 2. 布局调整
- **小屏幕：** 缩小字体和图标
- **大屏幕：** 保持原始尺寸，居中显示

---

## 九、可访问性 (Accessibility)

### 1. 视觉辅助
- **高对比度：** 确保文字和背景对比度足够
- **颜色盲友好：** 不仅依赖颜色传达信息
- **字体大小：** 可调节字体大小（未来）

### 2. 操作辅助
- **明确反馈：** 所有操作都有明确反馈
- **错误提示：** 清晰的错误提示信息
- **帮助系统：** 提供帮助文档（未来）

### 1. 主题系统

### 3. 个性化

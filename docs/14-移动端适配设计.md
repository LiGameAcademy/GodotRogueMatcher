# 移动端适配设计 (Mobile Adaptation Design)

---

## 一、设计原则 (Design Principles)

### 1. 核心原则
- **触控优先：** 所有操作都支持触控
- **响应式布局：** 适配不同屏幕尺寸
- **性能优化：** 确保移动端流畅运行
- **电池友好：** 优化电池消耗

### 2. 适配策略
- **提前设计：** 在开发初期就考虑移动端
- **渐进增强：** 先实现核心功能，再优化体验
- **测试驱动：** 在真实设备上测试

---

## 二、屏幕适配 (Screen Adaptation)

### 1. 屏幕尺寸

#### 1.1 目标分辨率
- **最小分辨率：** 720x1280（竖屏）
- **推荐分辨率：** 1080x1920（竖屏）
- **横屏支持：** 可选（未来扩展）

#### 1.2 适配方案
- **固定比例：** 保持游戏区域固定比例
- **缩放适配：** 根据屏幕尺寸缩放
- **黑边处理：** 小屏幕显示黑边，大屏幕居中显示

### 2. 布局调整

#### 2.1 竖屏布局
```
┌─────────────────┐
│   顶部栏         │
│  [安全等级] [分数]│
├─────────────────┤
│                 │
│   游戏区域       │
│   9x9 棋盘       │
│   (缩放适配)     │
│                 │
├─────────────────┤
│   商店栏         │
│  [商品] [商品]   │
└─────────────────┘
```

#### 2.2 横屏布局（未来）
- **旋转支持：** 支持屏幕旋转
- **布局调整：** 横屏时调整布局

## 三、触控操作 (Touch Controls)

### 1. 基础操作

#### 1.1 点击操作
- **选中棋子：** 点击有棋子的单元格
- **移动棋子：** 点击空单元格
- **放置物品：** 点击目标位置

#### 1.2 长按操作
- **显示信息：** 长按显示详细信息
- **取消选择：** 长按空白区域取消选择（可选）

#### 1.3 拖拽操作
- **从商店拖拽：** 从商店栏拖拽物品到棋盘
- **拖拽预览：** 显示半透明预览
- **释放确认：** 释放时确认放置

### 2. 手势操作（可选）

#### 2.1 双指缩放
- **缩放棋盘：** 双指缩放调整棋盘大小
- **缩放范围：** 0.8x - 1.2x
- **重置：** 双击重置缩放

#### 2.2 滑动操作
- **滑动查看：** 滑动查看棋盘（如果棋盘超出屏幕）
- **快速移动：** 滑动快速移动视角（可选）

---

## 四、UI 适配 (UI Adaptation)

### 1. 按钮尺寸

#### 1.1 最小尺寸
- **触控友好：** 至少 44x44 像素（Apple HIG 推荐）
- **推荐尺寸：** 60x60 像素
- **间距：** 至少 10px，避免误触

#### 1.2 按钮布局
- **底部固定：** 重要按钮放在底部，易于触控
- **避免边缘：** 避免按钮太靠近屏幕边缘

### 2. 文字大小

#### 2.1 可读性
- **最小字体：** 14px（确保可读）
- **推荐字体：** 16-18px
- **标题字体：** 20-24px

#### 2.2 自适应
- **根据屏幕：** 根据屏幕尺寸调整字体大小
- **用户设置：** 允许用户调整字体大小（未来）

### 3. 商店栏适配

#### 3.1 布局调整
- **横向滚动：** 如果商品太多，支持横向滚动
- **简化显示：** 移动端可以简化商品信息显示

#### 3.2 拖拽优化
- **拖拽区域：** 扩大拖拽区域，易于操作
- **视觉反馈：** 清晰的拖拽反馈

---

## 五、性能优化 (Performance Optimization)

### 1. 渲染优化

#### 1.1 降低画质
- **粒子数量：** 减少粒子数量
- **特效简化：** 简化特效效果
- **分辨率：** 降低渲染分辨率（可选）

#### 1.2 帧率控制
- **目标帧率：** 30 FPS（移动端）
- **自适应：** 根据设备性能自适应调整

### 2. 内存优化

#### 2.1 资源管理
- **纹理压缩：** 使用压缩纹理
- **对象池：** 使用对象池减少内存分配
- **及时释放：** 及时释放不用的资源

#### 2.2 内存监控
- **内存警告：** 处理内存警告
- **低内存模式：** 低内存时降低画质

## 六、输入处理 (Input Handling)

### 1. 输入检测

```gdscript
# 检测触控输入
func _input(event):
    if event is InputEventScreenTouch:
        if event.pressed:
            handle_touch_start(event.position)
        else:
            handle_touch_end(event.position)
    
    if event is InputEventScreenDrag:
        handle_touch_drag(event.position)

# 检测鼠标输入（PC端）
func _input(event):
    if event is InputEventMouseButton:
        if event.pressed:
            handle_click(event.position)
    
    if event is InputEventMouseMotion:
        handle_hover(event.position)
```

### 2. 统一输入接口

```gdscript
# 统一的输入处理
func handle_input(position: Vector2):
    # 检测点击的单元格
    var cell = get_cell_at_position(position)
    if cell:
        handle_cell_click(cell)
```

## 七、触觉反馈 (Haptic Feedback)

### 1. 震动反馈

#### 1.1 触发时机
- **点击：** 轻微震动（可选）
- **消除：** 中等震动
- **连击：** 强烈震动
- **失败：** 强烈震动

#### 1.2 实现方式
```gdscript
# Godot 4 触觉反馈
func vibrate(duration_ms: int = 100):
    if OS.has_feature("mobile"):
        Input.vibrate_handheld(duration_ms)
```

### 2. 震动强度
- **轻微：** 50ms
- **中等：** 100ms
- **强烈：** 200ms

## 八、电池优化 (Battery Optimization)

### 1. 性能优化
- **降低帧率：** 后台时降低帧率
- **暂停更新：** 应用进入后台时暂停更新

### 2. 屏幕优化
- **亮度控制：** 不控制屏幕亮度（由系统控制）
- **常亮：** 游戏进行时保持屏幕常亮

## 新局随机种子（#161 第一切片）

`RunSeedSource` 由 Board 实例持有，新局和 retry 经 `start_game()` 取新种子。
使用独立熵源，不消费局内落点、候选、目标、展示或出生内容随机流；同一入口相邻调用如碰撞则有界修正，避免复用上一种子。
这不是跨进程唯一性保证，种子也不是 run_id。

继续挑战不调用种子入口，保留五条流的 seed/state 和冻结补棋计划。
直接构造 `RunController(rules, seed)` 的开发与回放入口保持不变；既有子流派生和记录格式未改变。

# 单局表现 · M5-A / M5-B

M4最新轻量版去掉面板、来源与公式，只保留主分/额外分的分色数字；高分中心弹出与上漂完整包络纳入避让，低特效停止移动和缩放，淡出继续。旧版详细说明见下方历史记录，当前验收为`GDC/acceptance/juice-m4-轻量数字漂字验收.md`。

M4分数漂字：BoardView组合ScoreFloatLayer，读取冻结计分结果，在消除位置显示倍率后的主分和独立额外分；提示色、时间和排布预算由ScoreFloatConfig管理。漂字长尾不进入导演屏障，暂停/低特效/速度向下传递，取消清理、重试重置去重。面板样式按实例独占，不修改计分或随机。验收与Web链接见工程外`GDC/acceptance/juice-m4-分数漂字与收益认知验收.md`。

PresentationDirector场景拥有队列与epoch/token，父Board响应步骤信号，调用BoardView，实际动画结束后确认步骤。规则由RunController提交，播放不再次计分、抽选或推进随机。

PlaybackPlanBuilder在入队前复制路径、棋子与账本，保留规则事件顺序；同代匹配并行，跨代与逐枚出生顺序播放。旧SpawnManager也走同一队列，不独立创建出生Tween。奖励展示等待队列排空和已提交得分发布。

F8切换正常1×/快速2×，PresentationConfig管理速度、出生时长和故障保护阈值。移动、消除、出生、爆炸遵循速度，切换更新活动Tween；FIXED_REQUIRED使用自身时钟。暂停冻结动作和故障保护并停止后续派发，取消不视为完成。快速播放、低特效和音量通过插件ConfigManager保存，提示音使用插件AudioManager。

F9或右侧按钮请求略过本批可跳部分：MOVE、SPAWN、主五连与技能REMOVE属于COMPLETE_REQUIRED；只有爆炸代MATCHES为SKIPPABLE；每批末ALIGN为零时长FIXED_REQUIRED。混合匹配代只要包含主消除即为必播。请求遇到必播动作仍等自然完成；可跳代只取消所属动画、应用本代离场，不提前重建最终棋盘。ALIGN之后不跨到下批或技能选择；计分插值可立即到精确整数终值，不修改账本。

步骤epoch在跳过时递增，run epoch仅在取消/重试递增，旧步骤不能释放新屏障，正常跳过也不会误取消本局等待。音效长尾不进入屏障，取消演出时停止本场景仍借用的音频。

每批复制已提交结束快照，移动与主消除/爆炸合为一个批次。显示任务明确失败，或丢失完成通知触发StepGuard时，Board锁定输入并诊断；合法快照只恢复显示，不重发规则、分数、能力或候选。非法快照保持锁定和错误。保护默认10秒，每步至少保留duration×4+0.5秒；它只触发明确故障路径，正常推进仍依赖真实动画完成信号。

旧place/remove/color公开入口保留：若演出期间额外提交，途中冻结步骤不变，仅在整队列最终对齐时消费最新已提交快照，防止后面的旧ALIGN覆盖新变更。重建同步旧道具节点映射，不触发ON_PLACE。

三选一/结算沿用自身弹窗过渡与交互屏障，F9不作用于弹窗；未将所有UI过渡统一迁入导演。续局、首次接触者理解测试和D2节奏校准仍待实施，独立观看器继续消费33日志。

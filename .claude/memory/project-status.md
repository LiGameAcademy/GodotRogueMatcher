# 项目状态 - godot_banished_tutorials

## 项目概述

- **项目类型**: 殖民模拟 + Roguelike + 策略游戏
- **引擎**: Godot 4.6 + GDScript
- **目标用户**: 有 Godot 游戏开发经验的学员
- **项目规模**: 大型
- **教程方式**: 先MVP快速实现原型，之后分模块逐步讲解

## 世界观包装

- **题材**: 星际殖民
- **玩家角色**: 拓荒者，驾驶飞船在宇宙中寻找适合殖民的星球
- **核心机制**: 通过改造星球环境、收集资源、建造建筑、完成任务来积累声望
- **失败条件**: 所有殖民者死亡 / 规定时间结束未完成目标
- **胜利条件**: 积累足够声望（100%）

## 关键设计决策

1. **合成配方多选消耗**: 成品 = 材料1 + 材料2，最多两种材料，每种材料最多6个可选项
2. **配方与建筑绑定**: 每个合成配方绑定到特定建筑，不是通用加工站
3. **配方稀有度**: 普通/稀有/史诗，影响效率（1.0x / 1.25x / 1.5x）
4. **一次性资源采集**: 采集后地块枯竭变为荒地
5. **星球类型影响资源分布**: 森林/矿业/农业/冰冻/沙漠星球各有优势和劣势
6. **事件/危机表现形式**: 通过建筑物触发，不需要特殊地块
7. **贸易点**: 采用专门的建筑物方式

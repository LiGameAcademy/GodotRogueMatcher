# 反馈记录

## 2026-05-04 会话

### 经验教训

1. **设计阶段需要充分讨论**：在开始写设计文档之前，先与用户确认核心概念和机制，避免后期大幅修改

2. **资源命名需谨慎**：用户提供了《风暴之城》的资源列表，但有些资源是该游戏世界观特有的（如"野火精华"、"火花露"），需要及时识别并询问是否保留

3. **多选材料机制**：用户明确要求"材料多选"机制，这是合成配方系统的核心，需要在设计文档中详细说明

4. **一次性采集 vs 刷新**：用户选择一次性采集（不刷新），这简化了系统设计但增加了资源管理难度

5. **事件/危机不需要特殊地块**：用户明确事件和危机通过建筑物触发，这简化了地块系统的设计

### 设计方向确认

- 星际殖民题材（替换《风暴之城》的奇幻世界观）
- 6大类别资源，共54种资源
- 合成配方系统是核心核心
- 建筑系统采用"配方即建筑"的设计
- 教程采用先MVP后分模块讲解的顺序

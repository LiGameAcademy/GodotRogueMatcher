# 运行 HUD 原型

本轮按 GDC/08 的已确认布局补齐当前八项技能池的信息。顶部显示整数总分、最近增量、下一次技能选择差额与待选次数；左侧展示已获持续技能等级、机制摘要及即时取得历史；右侧展示最近根行动的 B×G+E 账本、已使用工具与播放控制；底部展示选中对象、操作反馈、空位和有效移动数。

Hud只保存显示数字和Tween。HudDetails格式化只读规则快照；总分、等级、占格与奖励仍分别由账本、RunState和BoardState拥有。Game传入数据、协调Board与HUD，HUD不查找棋盘。

消除/爆炸播放完成后，Board广播已提交总分，经Game提供的等待入口等待HUD增长完成，再开放奖励。重试递增HUD动画身份并取消旧等待；旧回调不能继续新局。快速模式同时加速棋盘和分数演出，暂停冻结必需演出；ESC和暂停按钮可恢复。奖励或结算弹窗存在时暂停请求不改变弹窗政策。

结算显示总分、有效移动、技能选择次数和最高单次根行动得分。没有角色选择、预览、暂存、阶段倒计时或续局的虚构入口。完整主菜单和最终美术仍属后续开发。

验证使用Godot 4.7.2和GUT：数字最终对齐、不重新入账、重试取消、暂停恢复、HUD数据与布局边界，以及原有快慢一致性、连续奖励、回放和采集回归。窗口目标为1280×720，字体、1920×1080缩放和首次接触者可读性仍需实机试玩。

## 棋盘空间修正

HUD使用MarginContainer/VBoxContainer/HBoxContainer统一分配顶部、两侧、中间BoardArea和底部空间。中央区域及其容器不拦截棋盘鼠标。Game收到区域变化后，按BoardView提供的实际边界居中等比缩放整个棋盘；第一格原点在中心，边界必须包含负半格和边框，不能从Board.position直接判断遮挡。

覆盖1280×720、1920×1080、1024×640和1600×720四种视口的真实首尾格边界、碰撞拾取及缩放后移动，规则快照不变。引擎离屏渲染检查1280/1920图像的留白与文本排版；系统字体缩放与外部试玩仍需后续验收。布局使用Godot原生容器；godot_core_system当前无对应布局模块，无需为此增加通用插件框架。

## 表现选项与插件接入

右侧提供低特效和音量。低特效关闭循环扫描、粒子、弹跳与额外闪光，保留选中缩放、路径提示、爆炸范围边框及必需移动/离场动画；切换不取消规则演出。Game 独占 Environment，棋子独占粒子材质，两个场景的效果切换互不影响。

PlayerPreferences 使用插件 ConfigManager 保存快速播放、低特效和音量到 user://rogue_matcher_settings.cfg；读取时校验类型与有限数值，缺失键使用默认值，保存失败显示操作反馈。音量拖动实时预览，松开或键盘调整时保存。此文件仅为设置，不是续局存档。

GameFeedback 使用插件 AudioManager 播放五类原型提示音，详见 [提示音说明](../gameplay/presentation/audio/README.md)。规则和账本不依赖音频或配置插件。本项目关闭尚未使用的 SaveManager 模块和自动保存，具体插件问题与待讨论升级见[插件接入记录](../../GDC/acceptance/m5b-插件接入问题.md)。

跳过按钮仍未提供：需要先为播放步骤建立终态对齐及可跳过政策，再验收奖励、暂停和重试边界。当前只有 1×/2× 和低特效，不能视为已完成31全部播放政策。

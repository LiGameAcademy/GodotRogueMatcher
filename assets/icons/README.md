# 道具图标说明 (Item Icons Documentation)

## 图标列表

所有图标均为 64x64 像素的 SVG 格式，采用赛博朋克风格设计。

### 1. prism_tower.svg - 棱镜塔
- **设计元素：** 菱形棱镜、渐变色彩、发光效果
- **颜色：** 青色到紫色的渐变 (#00ffff → #ff00ff)
- **特点：** 顶部光点、底部基座、内部高光

### 2. amplifier.svg - 增幅器
- **设计元素：** 圆形、同心圆环、信号线
- **颜色：** 黄色到橙色渐变 (#ffff00 → #ff8800)
- **特点：** 四个方向的信号线、中心点

### 3. dye_station.svg - 染色工厂
- **设计元素：** 方形、内部网格、管道
- **颜色：** 绿色渐变 (#00ff00 → #00aa00)
- **特点：** 顶部输入管道、底部输出、内部网格纹理

### 4. space_compressor.svg - 空间压缩机
- **设计元素：** 六边形、压缩箭头、压缩线
- **颜色：** 紫色到品红色渐变 (#8800ff → #ff00ff)
- **特点：** 左右压缩箭头、内部压缩线

### 5. ether_totem.svg - 以太图腾
- **设计元素：** 柱状图腾、装饰环、能量波纹
- **颜色：** 红色渐变 (#ff0000 → #aa0000)
- **特点：** 顶部装饰、中间装饰环、底部基座、能量波纹

### 6. energy_core.svg - 能量核心
- **设计元素：** 圆形、径向渐变、能量射线
- **颜色：** 白色到青色到蓝色径向渐变
- **特点：** 中心高光、内部能量环、八个方向的能量射线

### 7. bomb.svg - 炸弹
- **设计元素：** 圆形、引线、警告符号
- **颜色：** 红色渐变 (#ff0000 → #880000)
- **特点：** 顶部引线、警告符号、爆炸范围指示（虚线圆）

### 8. drill.svg - 钻头
- **设计元素：** 柱状、旋转纹理、火花效果
- **颜色：** 灰色主体、黄色/橙色尖端
- **特点：** 旋转纹理、顶部连接、底部火花效果

### 9. swapper.svg - 移位器
- **设计元素：** 两个方块、双向箭头、连接点
- **颜色：** 青色渐变 (#00ffff → #0088ff)
- **特点：** 左右两个方块、双向交换箭头、中心连接点

## 设计规范

### 颜色方案
- 遵循赛博朋克风格：高饱和度、霓虹色
- 主要颜色：青色 (#00ffff)、紫色 (#ff00ff)、红色 (#ff0000)、绿色 (#00ff00)、黄色 (#ffff00)

### 视觉效果
- 所有图标都包含发光效果（通过 SVG filter 实现）
- 使用渐变填充增强视觉深度
- 内部高光和细节增强辨识度

### 尺寸
- 标准尺寸：64x64 像素
- 视口：viewBox="0 0 64 64"
- 可在 Godot 中直接导入使用

## 使用方法

在 Godot 中使用：
1. 将 SVG 文件导入到项目中
2. 在 ItemData 资源中引用图标：
   ```gdscript
   @export var icon: Texture2D = preload("res://assets/icons/prism_tower.svg")
   ```

## 未来扩展

2. 使用相同的颜色方案和风格
3. 添加发光效果和渐变

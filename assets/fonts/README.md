# Noto Sans SC

Web不能依赖玩家操作系统的中文字体。本项目将Noto Sans SC Regular作为全局默认字体，覆盖HUD、弹窗、棋子标记与Tooltip；本轮不改变UI主题风格。

- 取得日期：2026-10-07；原文件未修改，仅工程路径使用snake_case。
- 工程文件：noto_sans_sc_regular.otf，8,331,336字节。
- SHA256：FAA6C9DF652116DDE789D351359F3D7E5D2285A2B2A1F04A2D7244DF706D5EA9。

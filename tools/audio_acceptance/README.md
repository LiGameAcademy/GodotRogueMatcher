# #130 坚果音效接入验收

运行 `godot --path . tools/audio_acceptance/audio_acceptance.tscn`，窗口标题“技能连珠 · 音效接入验收（#130）”。组合原#128真实Game夹具，不新增正式菜单/技能池入口，不保存玩家偏好、不记录真人数据。

- 默认普通移动/匹配：点“执行本例”，听落位与匹配；50分。重播先点同一案例重载。手动点击真实棋子可检查选中声。
- “爆破→横扫”和“横扫→爆破”：执行后分别61/16分，检查爆破/扫线音色区别及先后。无需安装新规则。
- “三类卡面”：执行打开真实奖励组，听候选声；选中并确认，听取得声。可查看棋盘/返回，检查暂停前的棋盘声不被奖励声替换。
- 普通/快速与普通/低特效独立切换；暂停/恢复、设置音量到0再恢复，重试检查旧声音停止。H隐藏/显示工具，窄窗口先收起再读盘。

重点由作者判断音量层次、音色契合、长链重复疲劳和等待感；自动回归不代替听感认可。没有新增胜利/阶段达成/染色专属声音，仍属后续范围。

可选音乐仍查找local_audio/gameplay.mp3，缺失时正常静默。本工作区没有复制私人音乐，不将音效许可自动套用音乐，也没有导出含音乐包。公开预设排除local_audio，实际成品导出/循环接缝不在本片验证范围。

追加 `-- --capture-audio` 会跑三种真实盘面×普通/快速/低特效/快速+低特效，共12组合；检查必要cue、固定分数及各模式规则快照一致，保存12张截图与results.json至`.godot/issue130-audio-validation/captures`。这是音效事件/规则技术证据，没有录制或自动评价实际声音。

本机GUI验证使用临时用户目录`.godot/icon_user`，避免读取真实玩家偏好；初始#198导入曾有尚未导入字体/Theme提示，最终重新导入与运行结果分别存档，不改全局编辑器设置。

# #130 普通出生与移动落定形变验收

运行 `res://tools/piece_motion_preview/piece_motion_preview.tscn`，使用真实Game，禁用用户偏好写入、遥测与试玩记录，没有覆盖操作区的额外测试面板。

1. 点击一枚普通坚果，再点可到达的空格。观察终点短暂横向挤压、纵向收紧后回正；选择光圈与格子点击区域不随挤压跳动。
2. 做一次不直接消除的移动，观察补棋出生：原有出现时长内，轻微拉伸→接触挤压→回正，没有新增逐枚等待。身体、五官和身份轮廓应对齐。
3. F1打开设置，分别使用普通、F8快速、低特效、快速＋低特效。低特效不播放挤压拉伸，必要出生与移动结果仍保留。形变过程中切换低特效应立即回正。
4. 通过暂停按钮在出生或移动中暂停/继续；重试新局。确认无残留扁棋子、错位轮廓、旧局尾迹或无法操作。
5. 可用现有F6爆破演示检查特殊标记；本片不扩展消除、爆破或扫线的形变设计。当前没有#201尚待review的UI动画，不代表回退已合并功能。

参数：出生局部拉伸(0.88,1.12)、接触挤压(1.10,0.94)，65%原出生时长到接触点，35%回正；移动落定仍为原60ms。以上为待作者试玩的表现参数，不是最终体验或帧时间门槛。

Windows启动采用短临时APPDATA/LOCALAPPDATA隔离目录（如 `%TEMP%/rogue-piece130-play`），避免长工作树路径导致shader缓存目录过深。`-- --capture-piece` 仅技术截图时暂停Tween并采样真实节点姿态，不冒充实时手感/帧时间或真人结果，输出到 `.godot/issue130-piece-motion/captures/` 后退出。

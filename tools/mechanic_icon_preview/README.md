# #129 首批机制图标试玩

运行 `godot --path . tools/mechanic_icon_preview/mechanic_icon_preview.tscn`。

- 默认展示强化三卡；左侧切换“登场三卡”“强化三卡”“构筑与回退”。
- 行扫箭头横向，列扫箭头纵向；爆破使用同一爆破图元。可选卡并确认，检查正式选卡及构筑刷新。
- 构筑样例同时展示登场、补给、范围与等级；未登记的留白调色仍保留文字缩写、剩余次数和提示。
- 支持中文/English、明亮/深色、普通/低特效；H 隐藏或显示左侧测试按钮。
- “查看技能池”核对相同机制图标；“查看棋盘”收起选卡后可查看构筑，再返回选择。

入口使用真实 Game、SkillRules 与选卡命令，固定种子129；只安装本片代表技能、人工提供奖励候选，不代表正式随机分布或平衡验收。不会保存玩家设置、记录回放或收集真人试玩数据。

追加 `-- --capture-icons` 可自动导出两语言、两主题、两尺寸的三类场景，共24张截图至 `.godot/issue129-icons/captures/`。

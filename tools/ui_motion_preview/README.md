# #130 主按钮与设置面板动画验收

运行 `res://tools/ui_motion_preview/ui_motion_preview.tscn`。使用真实 Game，关闭偏好持久化、试玩记录和遥测；主菜单从真实开始/继续流程进入。

1. 鼠标悬停主菜单“开始试玩”和设置按钮；Tab 切换焦点，空格/Enter 激活。检查焦点边框可见，色调过渡轻微，按钮和点击区域不移动。
2. 开始本局，悬停/按住 HUD 设置和暂停按钮。打开设置，检查面板短暂淡入；关闭或按 Esc/F1 后立即恢复原来暂停状态和焦点，短暂遮罩淡出不阻挡棋盘操作。
3. 快速重复打开/关闭设置；在手动暂停和未暂停状态分别测试。确认不残留透明遮罩、不自行恢复错误暂停状态。
4. 切换低特效：过渡立即停止，之后直接切换状态；关闭低特效恢复动画。F8 快进与低特效分别及同时打开，重复第2、3项。
5. 在设置中检查关闭、返回菜单、可用/禁用的跳过按钮；切换昼/夜主题、中文/英文，并缩窄窗口观察布局与文字。

按钮约90ms；设置淡入约140ms、关闭遮罩约90ms，仅为本片待试玩参数，不代表最终美学验收。真人观感由作者确认；自动回归不替代真人结果。

Windows自动启动验收时，建议把APPDATA/LOCALAPPDATA设为短临时隔离目录（例如`%TEMP%/rogue-ui130-play`），避免深层工作树中的shader缓存路径过长；不修改真实用户配置。

可用 `-- --capture-ui` 输出真实渲染截图到 `.godot/issue130-ui-motion/captures/` 后退出。

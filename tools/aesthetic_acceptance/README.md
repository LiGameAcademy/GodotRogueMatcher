# #128 坚果美学代表验收

在 Godot 打开本工作区，运行 `res://tools/aesthetic_acceptance/aesthetic_acceptance.tscn`，或使用 `godot --path <工程绝对路径> res://tools/aesthetic_acceptance/aesthetic_acceptance.tscn`。这是确定性展示夹具，不是正常随机局、平衡或 #119 真人样本；不写玩家偏好，不启用遥测/局记录。旧 F6/F7/F10/F11/F12 夹具禁用，正式菜单/技能池不增加入口或样片配方。

左侧选择案例，再点“执行本例”；点同一案例可完整重载。H 隐藏/显示验收工具，窄窗口和观察卡面时建议隐藏。普通/低特效和普通/快速独立切换；中文/English 切换后复查规则、次数与按钮。F1/设置和暂停沿正式 Game 行为。

## 人工判断

先用普通模式观察，再重载同例切低特效；快速只作补充比较，本片不声称 #130 完整四模式验收。建议依次检查：

1. 花生/腰果/杏仁/核桃/开心果能否迅速分清；选中四角、爆破描光、横/竖箭头是否遮脸或邻格。
2. 能否指出正反连携的起点、轴向、后续命中与最终得分；普通消除是否清楚且不刺眼，低特效仍保留事实。
3. 1024×640 和 1280×720 下切中英，三类规则、等级、次数、主题短句与确认操作是否可读；返回查看棋盘后选择仍在。
4. 暂停/恢复、设置返回及重载后是否有残留或误操作；声音是否叠得过响、过乱。已存 MP4 无音轨，听感请在游戏判断。

记录案例、模式、语言/窗口、具体误读/不适、采用/调整建议。主题短句是本片评审样例，复制定义只负责展示，不批量写入正式技能池。作者初步美学基线认可不自动等于这些动态情境通过。
